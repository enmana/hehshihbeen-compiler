数据表.hb

用 HB 自己写的库(仓库 Sample\库\*.hb),通过 包含 "../库/xxx.hb" 编译期内联;一个库一页:正文是库文件开头的说明注释(全文,不截),末尾那张公开方法表是从库源码的 方法 … 声明现场数出来的 —— 库里加一个方法,这一页就多一行。

数据表.hb —— 文件型定长记录表(纯 HB;不动 ISA、不动关键字、不动语言面)

用法:

包含 "../库/数据表.hb";
调用写 `数据表.建表(路径)` / `数据表.追加(路径, 记录长, 记录文)`

这一库不是 SQL:要一张"按顺序存、按主键找"的表,而不许引第三方库、不许整表进内存 ——
表就是盘上一个平铺的字节流,第 i 条记录的落点正好是 i × 记录长 字节,不用索引、不用表头。
30~33(打开库 / 执行语句 / 取一行 / 事务)判定不做、留号(登记在 未做任务清单.md)。

口径(2026-10-03;每条都对着实测结论写)

  • 建在流(48~54)与文件能力上:
    读走 打开读流 / 定位 / 读一块 / 关读流,
    写走 追加写文件。全程不整表读进内存,1MB 内存下可用;
  • 追加只能靠 追加写文件(整个库设计的地基):
    打开写流 是 FileMode.Create / C 后端 "wb",
    一开就把文件清空(先 定位 再写也救不回来)⇒ "接到表尾"只有 追加写文件(路径, 记录) 这一条路;
  • 记录长 / 主键偏移一律按字节算。别拿 .长度() 当字节数 —— 它数的是文字
    ("张三ab" 的 .长度() = 4,而它占 8 个字节)⇒ 库里自带字节级助手 字节长 / 取字节段;
  • 读一块 的上限必须是编译期字面量(语言口径)⇒ 库里把那条记录的字节数钉死成 8,
    取记录 / 按主键取 / 下一条 三处的 读一块(句柄, 块, 8) 就是它;
    调用方传别的 记录长 一律给空串 / 失败返回(不截断、不写半条)。
  • 读的时候一次只读"正好一条",不多读一个字节 —— 池里那块字符串的长度就是"真读到多少";
    多读(比如上限写 256)会在没写满的那截尾巴上让两个后端对不上;
  • 写一块 的第三个参数(字节数)也要编译期字面量 ⇒ 库里一律写 0(= 整段都写);
  • 主键固定 4 字节(与框架表那句一致;不做变长键)。键按字节比,
    拿 字节长(键) != 4 直接判不合法,不会"比着比着越界";
    比的是那 4 个字节,所以键请写成"能凑满 4 字节"的东西 ——
    用 4 个 ASCII(如 "0001")最省心;键里串了中文就是 3 字节一个字,
    两个汉字正好 4 字节、一个汉字得再补一个 ASCII(或补空格);
  • 不报错、不停机、不写错误槽:
    打不开 / 记录长不对 / 越界 / 没找到一律
    假 或 -1 或空串。

提供的函数(12 个):逐条的作用见本页末尾那张公开方法表。

边界(如实登记,不写"编译器的毛病 + 绕法")

  • 一条记录固定 8 字节(三处 读一块(…, 8) 那个编译期字面量);要换就一起改;
  • 主键固定 4 字节;主键必须落在 [主键偏移, 主键偏移 + 4) 这段里,越界直接给空串;
  • 按主键取是"从头扫"(O(记录数),一条一次 定位)——
    不是索引。小表(几千条)够用;要快的键值查找用 map.hb(哈希表);
  • 记录不许"写半条":
    追加 先比 字节长(记录) == 记录长,不等就拒收(返回 -1),
    所以表里永远是整数条、不会出现半条把后面全错位;
  • 同一个文件同时开两份写流会互相踩(流的 FileShare 只给 Read,这是语言那层的口径),
    本库只在 追加 那一刻开一下、写完立刻关,不做长事务;
  • 没有"按主键改 / 按主键删":
    那两件在"只有覆盖写 + 追加写"的能力下要么整表重写、
    要么引入空闲链表与表头,都不是一批能收口的东西(硬规矩 4:不留半成品)。要改就
    取记录 + 自己重写一份新表 + 改名 盖上去(原子写那一套,见 示例30_运行时);
  • 读出来的是"字符串",不是 出 参数:
    本批实测过 字符串 出 记录 这条路 ——
    传一个变量进去是好的,但"把调用结果直接赋给 出 参数"会拿到空串。
    这一库干脆不用 出,一律返回字符串(空串 = 没有),既避开那条边界,调用方也更好写;
  • 返回空串 = 没有这一条这条口径与"记录长最小是 1"配套:
    表里不存在空记录,
    所以空串不歧义(取记录 / 按主键取 / 下一条 三处都是这个意思)。

用法例子
包含 "../库/数据表.hb"
字符串 路径 = "数据/名单.bin";
数据表.建表(路径); // 空表
数据表.追加(路径, 8, "0001张三"); // -1:那是 10 字节,不是 8
数据表.追加(路径, 8, "0001张 "); // 0 (4 + 3 + 1 = 8 字节)
数据表.追加(路径, 8, "0002李 "); // 1
输出行(数据表.按主键取(路径, 8, 0, "0002")); // 0002李
输出行(数据表.取记录(路径, 1, 8)); // 0002李
输出行(数据表.记录数(路径, 8)); // 2

遍历那一套:
整数 句柄 = 数据表.开始遍历(路径);
字符串 这条 = 数据表.下一条(8);
当 (这条 != "") // 空串 = 没有下一条
{
输出行(这条);
这条 = 数据表.下一条(8);
}
