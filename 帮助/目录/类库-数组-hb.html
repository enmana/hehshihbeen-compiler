数组.hb

用 HB 自己写的库(仓库 Sample\库\*.hb),通过 包含 "../库/xxx.hb" 编译期内联;一个库一页:正文是库文件开头的说明注释(全文,不截),末尾那张公开方法表是从库源码的 方法 … 声明现场数出来的 —— 库里加一个方法,这一页就多一行。

数组.hb —— 定长数组算法库(纯 HB;不动 ISA、不动关键字、不动语言面)

调用写 数组.反转(表)
用法:

包含 "../库/数组.hb";

治的是每个程序都要手写一遍的那些动作(数一数有几个 / 倒过来 / 去掉重复 / 切一段 / 填充 / 取集合)。语言给数组的只有“取元素 / 改元素 / .长度()”,没有“整表搬一段”这种写法 ⇒ 这些函数一律自己走下标循环。

口径(2026-10;每条都对着实测写):

  • 一律 32 位有符号 整数:
    与语言内建的 整数 同一档;求和这一类会溢出的函数不在本库
    (那是 统计.hb 的事,它按 64 位累加),本库只做"搬 / 比 / 数",不产生新的数。
  • 只收定长数组(整数 表[10] 这种):
    动态列表(整数 表[])传不进来 ——
    报"列表的地址不能取"(与 排序.hb / 查找.hb / 测试助手.hb 同一条语言面边界)。
    列表那一半见 列表.hb(也不收列表形参,原因与做法写在那边的头注释里)。
  • 就地改 / 往外出,两条路分清:
    反转 / 交换 / 平移 / 填充 / 按位取反 就地改调用方那张表(传的是地址,没有副本);
    段拷 / 去重 / 造并集 / 造交集 / 造差集 / 合并 / 找全部 / 累计和 往另一张表写,
    返回值是写出去几个。
  • 容量不够不报错:
    能写几个写几个,返回值就是实际写出去的那个个数(调用方自己比对)。
    这一条是全库统一的 —— 没有一个函数会因为"目标表小了"而停机。
  • 越界下标一律夹回合法范围:
    段拷(表, 起, 个数, 出去) 里 起 是负的当 0、
    超过表长就当"这一趟没有可拷的" ⇒ 返回 0(不崩、不停机,与 查找.hb 一个规矩)。
  • 去重 / 集合那一族出来的表是升序的(不是"原来的先后"):
    去重要先复制一份再排
    (不然会打乱调用方的表),排完从前往后扫,相同的只留第一个。要"保持原有先后"的调用方
    自己另想办法(语言里没有哈希表内建,那件事要 map.hb 配合,不在本库)。
  • 合并 要求两张输入表各已升序(先用 排序.整数升序(表)),这一库不替调用方检查 ——
    没序也不会报错,只是结果不是有序表(如实登记,不静默排一遍:那是 O(n log n) 的额外开销)。
  • 空表 / 单元素表都给结果:
    个数 0 的段拷给 0、长度 1 的表反转后还是它自己。
  • 本库不可重入:
    去重 / 集合那一族借的是模块里两张 256 格的草稿纸(语言里"局部数组"
    也要占帧,96 字节的帧装不下 256 格)⇒ 同一时刻只能有一个 数组.* 在算。
    单线程程序不受影响;别把"本库函数的调用"套进另一个"本库函数的实参"里
    (那会让里层把外层的草稿纸盖掉 —— 本库没有一处这么写,示例与自检也没有)。

提供的函数(17 个):逐条的作用见本页末尾那张公开方法表。

英文对照:库里不另立英文函数(中英切换只管关键字与内建函数名,现有几个库也都只有中文名)⇒ 没有英文别名。

复杂度:计数 / 包含 / 下标 / 是相同 / 填充 / 累计和 / 段拷 / 找全部 O(表长);
反转 O(表长)(每个元素挪一次);交换 O(1);平移 O(表长);按位取反 O(段长);
去重 / 造并集 / 造交集 / 造差集 O(n²)(临时表上那一趟插入排序是 排序.hb 的同一套写法:
实现短、稳定、小表最快;上万条的表别用这一族);合并 O(表左 + 表右)(两边都已有序)。

边界(如实登记,不写"编译器的毛病 + 绕法"):

  • 不下标越界:
    所有下标参数先夹回合法范围,越界给"什么都没做"而不是停程序;
  • 目标表小了就只写一部分(见上面口径),调用方要的是"有没有写全"就看返回值;
  • 草稿纸 256 格:
    去重 / 集合那一族只看前 256 个元素(返回值会如实小于表长);
    要处理更长的表请分段调用 —— "定长数组不能动态要临时表"的直接后果,不是漏做;
  • 合并 不检查两表是否有序(要真有序先自己排;有序性检查是 查找.是升序);
  • 不做"整表赋值":
    语言里数组不能整块赋值,本库的"拷"一律是逐元素循环;
  • 不做排序 / 查找 / 求和:
    前两件在 排序.hb / 查找.hb,求和那一族在 统计.hb。

填充填充(整数 表[], 整数 值) 返回 整数就地把每一格都改成 值;返回一共填了几格(空表给 0)
按位取反按位取反(整数 表[], 整数 起点, 整数 个数)就地把 起点 起 个数 格逐格按位取反(~);越出表尾的自动截掉
段拷段拷(整数 表[], 整数 起, 整数 个数, 整数 出去[]) 返回 整数从 起 拷 个数 格到 出去;返回实际拷了几个,起 越界给 0
累计和累计和(整数 表[], 整数 出去[]) 返回 整数前缀和(出去[i] = 表[0] + … + 表[i]);取两表较短的长度
去重去重(整数 表[], 整数 出去[]) 返回 整数相同的值只留一个,按升序写进 出去;返回写了几个,只看前 256 格
造并集造并集(整数 表左[], 整数 表右[], 整数 出去[]) 返回 整数两张表合起来的全部不同值升序写进 出去;各取前 256 格,返回写了几个
造交集造交集(整数 表左[], 整数 表右[], 整数 出去[]) 返回 整数两张表都有的值升序写进 出去;各取前 256 格,没有共同值给 0
造差集造差集(整数 表左[], 整数 表右[], 整数 出去[]) 返回 整数只在 表左 有、表右 没有的值升序写进 出去;各取前 256 格
合并合并(整数 表左[], 整数 表右[], 整数 出去[]) 返回 整数把两张已升序的表归并写进 出去;重复值各出一份,不查有序性,合看前 256 格
是相同是相同(整数 表左[], 整数 表右[]) 返回 逻辑逐格比对两张表是否完全一样(格数也要一样);两张空表算相同
