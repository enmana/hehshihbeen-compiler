日志.hb

用 HB 自己写的库(仓库 Sample\库\*.hb),通过 包含 "../库/xxx.hb" 编译期内联;一个库一页:正文是库文件开头的说明注释(全文,不截),末尾那张公开方法表是从库源码的 方法 … 声明现场数出来的 —— 库里加一个方法,这一页就多一行。

日志.hb —— 分级日志(纯 HB 库:不动 ISA、不动关键字、不动机器码)

用法:

包含 "../库/日志.hb";
日志.开始(3, "运行.log");                 // 级别下限 3 = 只记 警告/错误;同时记进这个文件
日志.信息("程序起来了");                   // 2 < 3 ⇒ 不记(级别闸门在拼串之前就拦下)
日志.警告("磁盘快满了");
日志.错误("打不开输入文件");
日志.停止();                              // 关掉文件那一路

治的是“出事了才回去翻” 那件事:要“带时间、带级别、能只记关键的那几档、还能落到文件里回头看”,手写 输出行(“错误: ” + 消息) 每个程序都要重写一遍。

口径(2026-10;每条都对着实测写):

  • 三个开关,各管一条出路:
    ① 控制台那一路(输出行)默认开着,设控制台(假) 关掉它(关掉之后一条都不往 stdout 写);
    ② 文件那一路要 开始 或 设文件 给过路径才写;给空串 = 关掉它;
    ③ 环那一路(库自己留着的最近 64 条)取文本() 取,一直在记,没有单独的开关;
  • 级别:
    调试=1 · 信息=2 · 警告=3 · 错误=4;级别下限默认 2(信息及以上都记)。
    一次 写 先过闸门:级别 < 下限 ⇒ 直接返回假 —— 连时间戳都不取、连串都不拼
    (所以"调试那一档全开"在热路径里也不贵);
  • 一行长这样(字段之间一个空格):
    YYYY-MM-DD hh:mm:ss L 消息
    例:2026-10-08 14:03:21 警告 磁盘快满了。
    时间戳是墙上的钟(时间.现在秒() + 时间.按模板写),模板可以用 设模板 换;
  • 级别那一格是定宽的一个字:
    调试 / 信息 / 警告 / 错误 四个汉字各占 2 格 ⇒ 对齐的;
  • 控制台与文件写的是同一条串(只有一次拼装)⇒ 两边逐字节一致;
  • 文件是追加(追加写文件:
    不存在就新建、已存在接在末尾)⇒ 一次运行一份历史,不用自己先清;
  • 最近这些行留在库里:
    一个 64 条的环形表,取文本() 把"最近这些行"整段取回来
    (写超了从头覆盖最老的那一条 —— 这是"滚动"那一档,条数写死,不会把内存吃掉);
  • 不报错、不停机:
    文件写不进去(路径上没有目录 / 没权限)只是那一路不出结果,
    写 照旧按"控制台那一路出没出"给真假 —— 与 string.hb / 文件.hb 同一个规矩;
  • 取文本() 每次现造一条串(住在池里,由编译器按水位收)⇒ 别在循环里反复要它
    (要"边跑边看"就直接看控制台那一路,或者自己 设文件 落盘再看文件)。

提供的函数(23 个):逐条的作用见本页末尾那张公开方法表。

英文对照:库里不另立英文函数(中英切换只管关键字与内建函数名,现有几个库也都只有中文名)⇒ 没有英文别名。

复杂度:一次 写 是 O(时间戳 19 + 级别 2 + 消息字节数)(拼串那一遍)——
级别被挡下时是 O(1);取文本 是 O(环里那些条数);其余都是 O(1)。

内存账:固定的一张 64 格字符串环(每格一条日志行)+ 一条日志行串(每次 写 一条)+
级别下限 / 进环计数 / 两个落盘计数几个整数;取文本 另造一条结果串。
模块级变量都带 日志 前缀(语言现状:模块级私有变量会与调用方的顶层同名变量共用一格)。

边界(如实登记,不写"编译器的毛病 + 绕法"):

  • 只滚动、不轮转文件:
    文件那一路是纯追加,长跑要自己按大小切(库不做"到多少字节就换文件");
  • 环是按"条"滚的:
    只留最近 64 条(不是按字节),要留更多就 设文件 落盘再看文件;
  • 不做异步 / 不做后台刷盘:
    一次 写 就是一次宿主调用,单线程直着走(与语言同一套口径);
  • 不做"按模块分别设级别":
    级别只有一个(GUI / 网络那几个库将来要的话再开);
  • 一次 写 造两条串(日志行 + 环里那一格):
    极热的内层循环里逐次 调试() 会一直喂池 ——
    所以热路径上把级别下限提到 3 或 4(挡下时一条串都不造),这正是级别闸门排在最前面的原因。

取文件取文件() 返回 字符串现在往哪个文件追加;没接过或已关掉给空串
设控制台设控制台(逻辑 开) 返回 逻辑开 / 关控制台那一路;关掉后一条都不往 stdout 写,恒给真
取控制台取控制台() 返回 逻辑控制台那一路现在开没开;默认开着
设模板设模板(字符串 模板) 返回 逻辑换时间戳那一格怎么排;改完从下一笔起生效,恒给真
调试调试(字符串 消息) 返回 逻辑按 1 那一档记一笔;下限高于 1 时直接给假,一个字节都不往外送
信息信息(字符串 消息) 返回 逻辑按 2 那一档记一笔;下限被提到 3 或 4 时给假(不取时间、不拼串)
警告警告(字符串 消息) 返回 逻辑按 3 那一档记一笔;只有下限顶到 4(只留错误)时才给假
错误错误(字符串 消息) 返回 逻辑按 4 那一档记一笔;最粗的一档,下限再高也照样记、照样给真
写写(整数 级别, 字符串 消息) 返回 逻辑四个记一笔都走它:级别低于下限当场给假,否则拼成一行送给三条出路(控制台 / 文件 / 环各按自己的开关)
取文本取文本() 返回 字符串把环里留着的最近这些行整段取回来(最多 64 条,每条自带换行);没记过给空串
清掉清掉()把环里那 64 格清空、进环计数归 0;累计条数与文件那一路都不动
统计统计() 返回 整数真记下来过几笔(被级别挡下的不算);清掉环也不减
落盘落盘() 返回 整数文件那一路成功追加出去几笔;没接文件时一直是 0
落盘失败落盘失败() 返回 整数文件那一路写不进去几条(路径上没有目录 / 没权限)
级别名级别名(整数 级别) 返回 字符串级别号换成那一格两个汉字:1 及以下调试、2 信息、3 警告、4 及以上错误
