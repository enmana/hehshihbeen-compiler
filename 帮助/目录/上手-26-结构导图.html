26,结构导图

【一句话】把 .hb 源码编译成 4 字节定长指令,在自带虚拟机里跑,并对照注释里的期望值做断言。
下面是 34 节手写教程,与命令行 hbcc --help-text 的《快速上手》同一份正文(站点在生成时现场拆开,改一处两边都变)。

  • 一个文件 = 一个类:
    点开一个文件先看见两个可折叠的大框:声明区(它自己声明的变量 / 常量 / 结构 / 方法 / 包含)与调用区(它直接挂着的
    语句与流程块,每条语句再往下长成调用链);两个大框点一下展开、再点一下 = 收起。声明项就是那个框(「求和 整数」「结构 分数」点得开,展开就是
    它自己的声明区 / 调用区);顶层流程块归调用区
  • 框上只写文件名,全路径放进鼠标提示(工程框同办:
    框上只有工程名);左边竖排的种类名(方法 / 变量 / 常量 / 结构 / 流程块);子项多了就把间距拉开(≥8 / ≥15 / ≥25 条)
  • 两个入口(都是右键):资源管理器 → 打开思维导图(从点的那一个节点起)/ 编辑器 → 打开思维导图(从当前文件起)
  • 一个浮动窗靠在主窗口右侧;连线是弧线(不用折线);声明线画虚线、调用线画实线;名字顺着虚线能找到声明处
  • 只画相关的那些框(默认):
    画面上只留它到根的父链 + 它自己 + 直接子,兄弟枝与走过的旁支收起来不画(数据还在,只是不占画面);顶上「全集图」开关勾上就全都画(切来切去只换画面,不动树)
  • 找名字:
    左上打一个名字(方法 / 变量 / 常量 / 结构 / 参数 / 局部都认),回车就铺到它声明的那一格并选中;这一份里没有就去整个工程里找
    (含 包含 进来的库),声明在别的文件时会换一张图从那一份文件起;内建函数 / 关键字没有源码定义,如实说一句
  • 看谁调用它(方法框上右键):
    列出调用它的地方(文件 + 行 + 是谁调的,双击跳过去),数据是整个工程的调用边;原地展开的写法不发 CALL,查不到
    时如实说一句。同一个框里同名的只列一次(去重粒度是"框 + 名字")
  • 状态行报"当前选中那一格"(标题 · 种类 · 第几行 · 哪一个文件);操作说明都挪进了它的鼠标提示**
  • 缩放 / 适应窗口:
    滑条 5% ~ 300% + 「适应窗口」;按住 Ctrl 滚轮也缩放,裸滚轮照旧是滚动
  • 红线指回声明处:
    名字就声明在本文件时,导图自己把声明区那一枝展开,再拉一条红色弧线指回那一条(方法 / 结构 指那个框;变量 / 常量 / 参数 /
    局部 / 字段 指那一条声明项);变量的调用同办;跨文件 / 内建函数 / 关键字那种给一个"→ 声明处"小框;收枝时红线一起清掉,不会留一条悬空的线
  • 跟着调用走:
    调用链上带括号那一格,只要那个方法有源码定义,下面就挂那个方法的框,于是一条多文件调用链(主程序.hb → 打印表 →
    排序.整数升序 → …)一次都不跳编辑器就走得完(走得到 库\排序.hb)
  • 框宽收在一个区间里:
    最窄 140、最宽 340 像素;点过的框到根节点那一串连接线画成绿色
  • 文件框的两个区标题下面有一排斜体小字「此为思维导图虚拟概念」,这排小字只在文件框上写一遍;颜色取编辑器那套高亮配色
  • 双击一个框 → 跳到代码;跳过来的是「预览页」(页头标题斜体、同一时刻只留一个):
    留住它的三条路 —— ① 在里面改一下、
    ② 再双击导图里那一格、或双击标签头空白处
  • 长出来的东西不会丢(收起来不画,勾「全集图」还看得见);一层最多先出 20 条(还有剩就挂一条「…」);前后追溯:
    ← 上一个 / 下一个 → 在点开过
    的框之间前后走,回到根 / 全部收起;框上右键还有「收起这一枝」「复制标题」
  • 数据来自这份文件自己的文本(按花括号分块扫出结构,再拼上每个名字的声明处);工程 → 文件那一层按工程文件表顺序
