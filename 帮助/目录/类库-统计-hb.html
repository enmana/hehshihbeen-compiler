统计.hb

用 HB 自己写的库(仓库 Sample\库\*.hb),通过 包含 "../库/xxx.hb" 编译期内联;一个库一页:正文是库文件开头的说明注释(全文,不截),末尾那张公开方法表是从库源码的 方法 … 声明现场数出来的 —— 库里加一个方法,这一页就多一行。

统计.hb —— 统计库(纯 HB;不动 ISA、不动关键字、不动语言面)

用法:

包含 "../库/统计.hb";
调用写 `统计.平均值(表)`

治的是“一共多少 / 平均多少 / 波动多大 / 中间那个是多少”这几件 —— 每一件都要先想清楚溢出与小数(求和会冲破 32 位、平均值不是整数),这一库一次办掉。

依赖两个现成的库(不是第三方,零依赖的承诺没破):int64s.hb 让累加器走 64 位(32 位累加等于把“溢出”当正常结果给用户;最后回到 整数 时是低 32 位);float64.hb 因为平均值 / 方差 / 标准差结果本来就是小数。

口径(2026-10;每条都对着实测写):

  • 一律 32 位有符号 整数 当输入:
    表里装的就是内建 整数(4 字节一格)。
  • 求和 / 乘积 / 平方和 累加时按 64 位(不中途溢出),交给调用方时回到 整数
    (低 32 位回绕)。要 64 位的和,直接用 长整数 那一档自己累加 —— 本库不返回结构。
  • 平均值 / 方差 / 标准差 返回 双精度(float64.hb 的结构):
    要打印用 双精度转字符串(值),要比大小用 双精度比较 / 双精度小于 那一套
    (结构不能直接写进 输出行,也不能用 > 比 —— 那是 float64.hb 的口径)。
  • 方差是"样本方差"(除以 n-1),总体方差是除以 n:
    两个都给了,调用方按用途挑。
    表里只有 1 个元素时样本方差给 0(分母 0 那一档不报错、不停机)。
  • 中位数 / 众数 是"数值统计":
    中位数 = 排序后正中间那个;偶数个取中间两个的整数平均
    (向下取整,不是小数)。众数 = 出现次数最多的那个值,并列时取最小的那个(排序后先遇到)。
  • 排序只在内部进行:
    临时表是模块级的一张 256 格草稿纸,排完不动调用方那张表。
  • 表比 256 长时只统计前 256 个:
    定长数组不能动态要临时表(与 数组.hb 同一条边界)。
    求和 / 乘积 / 平方和 / 最大 / 最小 / 个数 这几件不经过临时表,多长的表都算。
  • 空表:
    个数给 0、求和/乘积给 0/1、最大/最小给 0、平均给 0、方差给 0、中位数给 0、
    众数给 0 —— 没有一个函数会因为"表是空的"停程序。要区分"0"与"没有",先用 个数 问一句。
  • 不做浮点表、不做直方图:
    元素类型就是 整数;直方图要"按组数填一张计数表",
    那张表得多大是调用方定的(定长数组长度写死在源码里),本库不当第二个收表的形参
    —— 要做直方图请照 个数 + 数组.计数 自己写(三行)。

提供的函数(17 个):逐条的作用见本页末尾那张公开方法表。

英文对照:库里不另立英文函数(中英切换只管关键字与内建函数名,现有几个库也都只有中文名)⇒ 没有英文别名。

复杂度:求和 / 乘积 / 平方和 / 最大 / 最小 / 极差 / 个数 O(表长);
中位数 / 众数 / 第k小 O(n²)(那一趟插入排序的钱;n 是 256 以内);
平均值 O(表长);方差 / 标准差 O(表长)(平方和是一趟走完,不排)。

边界(如实登记,不写"编译器的毛病 + 绕法"):

  • 结果回到 整数 会回绕:
    求和 超过 21.47 亿就按 32 位回绕(与语言自己的 + 一样);
    要真正的大和请自己用 长整数 累加(本库不返回结构,一个返回值只能是一种类型);
  • 平均值 / 方差 / 标准差 是 双精度:
    输出行(统计.平均值(表)) 打不出来
    (结构不是标量),要先 双精度转字符串 再打印 —— 示例 38 与自检都照这条写;
  • 草稿纸 256 格(见上面口径):
    中位数 / 众数 / 第k小 只看前 256 个;
  • 取草稿 / 草稿个数 是给"想知道排序结果长什么样"的调用方,平时用不上;
    它们读的是模块里那张草稿纸,两次调用之间如果又算了别的统计,内容会被换掉;
  • 不做加权 / 不做分组 / 不做回归:
    本库只做"一张整数表的基本统计量"。

标准差标准差(整数 表[]) 返回 双精度把 总体方差 开平方得到的 双精度;空表给 0,内部不排表
是否升序是否升序(整数 表[]) 返回 逻辑逐格看后一格是否小于前一格;都不小给真,空表和单格表给真
第k小第k小(整数 表[], 整数 k) 返回 整数排序后第 k 个值(k 从 1 数起);越界给 0,只看前 256 格,不动调用方的表
中位数中位数(整数 表[]) 返回 整数排序后正中间的值;偶数格取中间两格的整数平均,空表给 0,只看前 256 格
众数众数(整数 表[]) 返回 整数出现次数最多的值(并列时取最小的那个);空表给 0,只看前 256 格
草稿个数草稿个数() 返回 整数上一次排序生效的格数(配合 取草稿 用)
取草稿取草稿(整数 下标) 返回 整数读上一次排序留在草稿纸上的第 下标 格;下标越界给 0,再算别的统计会被换掉
