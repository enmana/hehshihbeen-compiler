Markdown.hb

用 HB 自己写的库(仓库 Sample\库\*.hb),通过 包含 "../库/xxx.hb" 编译期内联;一个库一页:正文是库文件开头的说明注释(全文,不截),末尾那张公开方法表是从库源码的 方法 … 声明现场数出来的 —— 库里加一个方法,这一页就多一行。

Markdown.hb —— Markdown 的写与读(纯 HB,零依赖;不动 ISA、不动关键字、不动语言面)

用法:

包含 "../库/Markdown.hb"
Markdown.开始();  Markdown.标题(1, "周报");  Markdown.段落("正文……");
字符串 全篇 = "";  Markdown.取结果(全篇);     // 写:一整份 `.md` 写进你那一格

整数 文档 = Markdown.解析(全篇);             // 读:整份解析一次
整数 种类 = 0;  字符串 文本 = "";
Markdown.取块(文档, 0, 种类, 文本);          // 种类:1 标题 / 2 段落 / 3 要点 …
Markdown.转HTML(文档, 文本);                 // 一段 HTML 片断

写盘不归它管:要落成 .md 文件配 文件.hb。

口径(2026-10;每条都对着实测写):

  • 写:一个缓冲,最后取一次。标题 / 段落 / … 往库里那一格追加,取结果(出 文) 把整份写进你给的
    字符串变量;反复写同一份只占一格。换行一律 \n;"写一条"后面空一行(代码块 前后都空)。
  • 读:两层结构。块层按行认;行内层认粗体 / 斜体 / 行内代码 / 链接 / 图片,其余字节算正文。文本按
    字节收进库里的字节区,块与行内只记 起 / 长;取块 / 取行内 / 转纯文本 / 转HTML 写进你那一格。
  • 行内平铺:
    **粗 *斜* 体** 只认成一段粗体,里层 * 是普通字符(不递归)。
  • 表格:
    写收"一行一条"的整串(\n 分行、| 分格,第一行当列头);读按 | 切格、两头去空白;
    格号用 行首格(文档, 块, 行) / 行格数(文档, 块, 行) 问。
  • 转义认十二个字符:
    \ ` ` * _ { } [ ] # + | ~,外加 < > &`;
    ! - . ( 不动。标题 / 要点 / 编号 / 引用 / 清单 / 链接 / 图片 里该躲的自动躲,段落 只躲行首 #。
  • 中英空格:
    中日韩字与 ASCII 字母数字之间补一个空格;两边有一边是空白 / 标点就不补。
  • 转 HTML 只做最小那一套:
    <p> <h1>~<h6> <ul>/<ol>/<li> <blockquote> <pre><code>
    <table> 那一族 <hr> <strong> <em> <code> <a href> <img src alt>;正文按 HTML 五个字符转义。
  • 不报错、不停机:
    认不出的写法当正文,越界给假 / 给 0。

提供的函数(32 个):写 19 + 读 13(解析 / 块数 / 取块 / 取行内 / 转HTML / 清空 / …),
逐条的作用见本页末尾那张公开方法表。

英文对照:库里不另立英文函数(中英切换只管关键字与内建函数名,现有几个库也都只有中文名)⇒ 没有英文别名。

复杂度:写是一下 O(这段文本字节数),取结果 O(整份字节数);解析 O(这份文本字节数);
取块 / 取行内 O(这一段字节数);转纯文本 / 转HTML O(整份字节数 + 结果字节数)。
⚠ 转义 / 中英空格 按文字下标读入参(文本[i] 是 O(下标))—— 只适合一段话这个量级。

内存账:字节区 8KB × 8 份 = 64KB 静态数据(一块 字符 数组,65536 字节),外加块表 64 × 10 与
行内表 512 × 6(约 15KB)—— 一共约 80KB,不进堆、不进池。装得下"一份 8KB / 64 个块 / 512 个行内";
第 9 份文档起覆盖最早那一份(表是环形的)。

边界(如实登记):

  • 不做 CommonMark 全套:
    引用里套列表、脚注、HTML 块、引用式链接都不认;
  • 认的块:
    # ~###### 标题 · 空行分段的正文 · - / * / + 要点 · 数字. 编号 · > 引用 ·
  · **认的行内**:`` ` `` 行内代码 · `**粗**` / `__粗__` · `*斜*` / `_斜_` · `[文本](地址)` / `![文本](地址)`;
    `---` 单独立行算分隔线(不认下划线标题);表格以列头那一行的格数为准,多出来的格丢掉;
  · **交付那一格用整串赋值**:别在 `出` 参数上先清空再拼、也别把 `出` 参数转交给另一个 `出` 函数;
  · **一份文档别超过 8KB**(字节区是一块 `字符` 数组,语言里定长数组最多 65536 格);
  · **不认 BOM**:开头带 `\uFEFF` 算正文第一个字符;`清空()` 之后旧文档号作废。
