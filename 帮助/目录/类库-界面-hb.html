界面.hb

用 HB 自己写的库(仓库 Sample\库\*.hb),通过 包含 "../库/xxx.hb" 编译期内联;一个库一页:正文是库文件开头的说明注释(全文,不截),末尾那张公开方法表是从库源码的 方法 … 声明现场数出来的 —— 库里加一个方法,这一页就多一行。

界面.hb —— 控件库(标签 / 按钮 / 文本框 / 列表 / 复选框 / 单选组 / 进度条;纯 HB 库,不动 ISA、不动关键字)

用法:包含 "../../库/界面.hb"

口径(2026-09):

  • 即时模式:
    库不持有窗口,也不替你 刷新() —— 一帧的顺序永远是「收事件 → 送事件 → 要重画? →
    重画 → 刷新()」,帧边界在程序手里。干净的一帧照样要 刷新(),但一条绘制命令都不发。
  • 一屏一表:
    控件按号存在 界面 里的一片平行列表上(类型[] / 左[] / 上[] / 宽[] / 高[] /
    文本号[] / 值[] / 项起[] / 项数[] / 行高[] / 显示[]),号就是下标,从 0 起、后加的盖在上面;
    文本住两个顶层池(控件文本池 / 列表项池),控件里只存下标,同一程序里多开几个界面池子一起长。
  • 布局:
    纵向堆叠。建界面(面, x, y, 宽, 间距) 给出列左边界、第一个控件的上边、列宽与间距,之后每加
    一个控件就把落点往下推(标签 22 / 按钮 30 / 文本框 30 / 复选框 26 / 单选组 26 / 进度条 12;列表高 =
    行数 × 行高)。要另外摆用 摆到 / 设为宽高(摆了之后库自己标脏)。
  • 命中测试:
    从最后加的往前找(后加的盖在上面),显示 == 假 的跳过;不在任何控件上给 -1;
    列表还要再往里算一行(命中行)。
  • 重绘调度:
    改了什么就 标脏(所有会改状态的库函数都替你标了);要重画 问一句,重画 才真发绘制
    命令(清屏 + 每个可见控件),回来的是这一帧发了几条命令,顺手把脏清掉。
  • 点一下 = 按下 + 抬起:
    按下 记在按钮上、抬起 还在同一个按钮上才算数;取点击 取一次就清掉。
  • 文本框只吃 ASCII 可见字符(32~126)与退格(8);中文输入要平台输入法,本版不做。
  • 键码沿用宿主那套(图形键C):
    编辑键 / 方向键取老虚拟键编号,字母数字取 ASCII;源码里比键码不必写
    数字 —— 键回车() / 键退格() / 键制表() / 键空格() / 键退出() 就是那几个常量。
  • 不报错、不停机:
    命中不到给 -1,行号越界给 假,状态查询都给确定值。

配色(库内写死,一屏一个口径;要换色就改 重画 那一族里的颜色字面量):
