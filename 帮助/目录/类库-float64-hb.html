float64.hb

用 HB 自己写的库(仓库 Sample\库\*.hb),通过 包含 "../库/xxx.hb" 编译期内联;一个库一页:正文是库文件开头的说明注释(全文,不截),末尾那张公开方法表是从库源码的 方法 … 声明现场数出来的 —— 库里加一个方法,这一页就多一行。

float64.hb —— IEEE754 双精度浮点库(纯软件;不动指令集、不动语言面)

值 = 双精度 位模式(64 位 = 高 32 + 低 32):
高 = (号 << 31) | (阶 << 20) | 尾数的高 20 位;低 = 尾数的低 32 位
阶 0 = 零/次正规;阶 1..2046 = 正规(隐含位 1);阶 2047 = Inf/非数;
尾数 52 位(正规数的实际尾数 53 位,隐含的最高位 1)。

与 float32.hb 各自独立(都能单独 包含),但两库的 宽整数* 帮手重名 ⇒ 同时 包含 时
会被后解析的那个顶掉,要一起用就自己给其中一个加前缀。

口径(2026-10;与 IEEE754 一致,除非特别注明):

  • 加 / 减 / 乘 / 除 / 开方 / 比较 / 取负 / 绝对值一律"就近连偶";负数、-0.0、±Inf、
    非数(安静 非数 一律 0x7FF8000000000000)全按 IEEE754;
  • 打印最短且能原样读回;|二进指数| > 53(约 1e-16 以下、9.0e15 以上)退回精确二进制写法;
  • 解析收 16 位有效数字;|十进指数| ≤ 22 一步算准,更大按 22 一段算(可能差 1~2 个最小单位)。

用法:在文件开头 包含 "../库/float64.hb"
性能:字符串转双精度 是运行期解析(几十~几百条指令),热循环里别调 —— 常量写位模式
(0x400921FB54442D18)或用 双精度常量圆周率()(零运行期开销)。

提供的函数/英文对照/复杂度:/边界(如实登记):依次见上面那一栏、本页末尾那张公开方法表与各函数紧上面那行注释;越界 / 装不下 / 认不出都不报错、不停机。
依赖:string.hb(用它的 转字符串 / 取子串)
