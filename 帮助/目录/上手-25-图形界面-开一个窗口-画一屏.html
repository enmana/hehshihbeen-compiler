25,图形界面:开一个窗口、画一屏

【一句话】把 .hb 源码编译成 4 字节定长指令,在自带虚拟机里跑,并对照注释里的期望值做断言。
下面是 34 节手写教程,与命令行 hbcc --help-text 的《快速上手》同一份正文(站点在生成时现场拆开,改一处两边都变)。

  • 这一门语言不做控件库:窗口、像素、输入是宿主给的,控件(按钮 / 文本框 / 列表 / 布局)由 HB 自己写 —— 每帧重画一遍(即时模式),状态就是普通变量。
    这一批有 10 条原语(不是关键字,与 读文件 同一档内建函数;中英可整体切换):
    逻辑 开 = 打开窗口("HB 图形演示", 320, 200);
    如果 (开) { 当 (真) {
    清屏(0xFF101018); // 整窗铺一个底色(命令,没有返回值)
    画矩形(10, 10, 120, 40, 0xFF2A6EF0); // 填充矩形
    画文字(16, 24, "你好,HB", 0xFFFFFFFF); // 等宽单行
    画线(0, 60, 319, 60, 0xFF3C3C46);
    刷新(); // 不刷新就一直不显示
    等待(16); // 让出一帧,别把 CPU 烧满
    整数 类型; 整数 键码; 整数 x; 整数 y;
    如果 (取事件(类型, 键码, x, y)) { 如果 (类型 == 1) { 跳出; } } // 1 = 关窗;不阻塞
    } 关闭窗口(); }
  • 命令那一档没有返回值(单独成句写):
    清屏(颜色) / 画文字(x, y, 文本, 颜色) / 画矩形(x, y, 宽, 高, 颜色) / 画线(x1, y1, x2, y2, 颜色) /
    等待(毫秒) / 关闭窗口() / 刷新();有返回值那一档:打开窗口 与 取事件 返回 逻辑,取文字宽度(文本) 返回 整数(等宽口径:ASCII 1 格、
    汉字 2 格)
  • 取事件 的四个实参要写变量名(事件的值写回它们);类型五种:1 关窗 / 2 按键 / 3 移动 / 4 按下 / 5 抬起(同一个键码凑成一次"点一下")。
    键码表:字母 = ASCII 大写(A 65 ~ Z 90)、数字 = ASCII(0 48 ~ 9 57)、F1~F12 = 112~123;编辑键 / 方向键 / 修饰键走虚拟键编号:
    回车 13 / Esc 27 / 空格 32 / 退格 8 / 制表 9 / Shift 16 / Ctrl 17 / Alt 18 / 左 37 / 上 38 / 右 39 / 下 40 / 首页 36 / 末页 35 / 上一页 33 /
    下一页 34 / 插入 45 / 删除 46 / 鼠标左键 1 / 中键 2 / 右键 3
  • 时钟:
    等待(毫秒) 就是"让出一帧"(即时模式的主循环里每帧调一次);桌面壳上它真睡这么久;无头呈现(hbcc --run / 自检)不真等。要算"两帧
    之间过了多久"用 当前毫秒() —— 单调钟的毫秒刻度,低 32 位、约 49.7 天回到 0(别拿它当绝对时刻比大小,只拿它算差)
  • 定时器用标准库 Sample\库\定时.hb:
    开头 包含 "../../库/定时.hb",主循环里每轮 定时.推进(),登记写 定时.每(16, 地址(动一下)); /
    定时.一次(3000, 地址(收手));,要停就 定时.取消(号)(标准工程 示例28_定时器)
  • 关窗请求:
    用户点标题栏的叉 ⇒ 宿主投一个 类型 == 1 的事件;主循环该照抄上面那段"取到 1 就 跳出"。宿主不会替你结束进程
  • 事件脚本(只给确定性测试用):
    一份写死的输入 —— 第几帧投哪个事件。文件叫 事件脚本.txt,放在工程目录里(自检 自动认);命令行是
    hbcc 主程序.hb --run --事件脚本 事件脚本.txt。格式(一行一条,# 或 // 起头是注释):帧数 4(必写;跑满投一个"关窗请求")/
    帧 0 按键 回车(第 0 帧 = 打开窗口之后)/ 帧 1 移动 100 60(鼠标移动 x y)/ 帧 2 按下 鼠标左键 10 40(鼠标键按下,键码 x y)/
    帧 3 按键 字母A(数字键要写 数字5)。帧号:打开窗口 之后是第 0 帧,每 刷新() 一次提交一帧;跑满 帧数 帧还没收手(再刷 4 帧 = 那道
    宽限)⇒ 带行号的运行期错误。加 --跨进程 也认
  • 画在哪儿看宿主(三条路,同一套原语):
    ① IDE 里按 F5 / 单步 = IDE 自己的窗口(跑程序那台机器在子进程里、窗口仍画在 IDE 这一侧 —— 断点 /
    单步 / 变量面板照旧插得进,引擎崩了也带不走界面);⚠ 这类窗口程序转到用户自己关窗,所以它会一直跑下去;② 桌面壳(HB宿主 那条路,含带壳的
    独立 exe)= Avalonia 真窗口;③ hbcc --run = 无头 —— 每种命令按同一份格式逐条打出来(清屏 颜色=0x101018 / `画文字 x=… y=… 文本="…"
    颜色=0x… / 刷新 命令=N`),所以不开窗也能验
  • 没挂图形能力的宿主(独立 exe 没带壳、手机端)一律给 假;取文字宽度 是纯计算,照常给数
  • 位图(离屏画布,功能号 70~78):
    建位图(宽, 高, 句柄变量) 拿一个宿主侧的句柄,图不占那 1MB 运行内存;拿它去 画点到图 / 画线到图 /
    画矩形到图;画完用 贴位图(句柄, x, y) 一次贴一整块到窗口上。取图像素(句柄, x, y) 读一个像素(0xAARRGGBB,坐标越界给 0);位图尺寸 问
    大小;释放位图 还回去(句柄从 1 起、旧号永不复用);现成入口在库 Sample\库\位图.hb(活例子 示例62_位图)。号 78 `贴文字到位图(句柄, x, y,
    文本, 颜色) 把一行字**画进那张图**,但它**要呈现口** ⇒ **无头那条路(hbcc --run`)给 假、一个像素都不动;两套字体栈不保证光栅化逐字节相同**
    ⇒ 跨腿判据只做到形状级
  • 窗口的显示时长由程序自己定:
