中文.hb

用 HB 自己写的库(仓库 Sample\库\*.hb),通过 包含 "../库/xxx.hb" 编译期内联;一个库一页:正文是库文件开头的说明注释(全文,不截),末尾那张公开方法表是从库源码的 方法 … 声明现场数出来的 —— 库里加一个方法,这一页就多一行。

中文.hb —— 中文文本的三件事:UTF-8 一字、汉字、中文数字(纯 HB,零依赖)

用法:

包含 "../库/中文.hb";
如果 (中文.是汉字(名字[0])) { … }
整数 宽 = 0;
无符号整数 码 = 中文.UTF8解码一字(文本, 字节位, 宽);   // 宽 写回这个字占几个字节
输出行(中文.汉字个数("张三丰 2026"));                  // 3
输出行(中文.转半角("ＡＢＣ１２３"));                     // ABC123
整数 值 = 0;
如果 (中文.中文数字转整数("一万零五", 值)) { 输出行(值); }   // 10005
输出行(中文.整数转中文数字(20261005));                  // 二千零二十六万一千零五
输出行(中文.金额大写(12345));                            // 壹佰贰拾叁元肆角伍分

这门语言是中文优先的,而"中文"在字节那一层是变长的(一个汉字 3 个字节),在语义那一层是
一个字一个码点。这中间的活分三族:① UTF-8 一字(按字节定位到字边界、码点编回字节串);
② 汉字(是不是、几个、滤掉非汉字);③ 中文数字(与整数互转,外加票据那套金额大写)。

口径(2026-10;每条都对着实测写):

  • 长度与下标一律按"文字"(Unicode 码点)算:
    文本[i] 取出来是一个 文字,不是字节 ——
    "第几个字节"这件事得走 UTF8解码一字;
  • UTF8解码一字 的 起 是"第几个字节"(0 起),必须落在某个文字的起始字节上:
    正好落在字边界上
    就给那个字的码点、宽 写成它占几个字节(1~4);越过末尾 / 落在字中间一律给 4294967295
    (0xFFFFFFFF;输出行 打出来是 -1)、宽 给 0,不停机;
  • UTF8编码一字 收任何数字都不报错:
    码点越界(> 1114111)或落在代理区(0xD800~0xDFFF)
    给空串;1~4 字节按 UTF-8 正常装;
  • 是汉字 认这六段(其余一律假):
    0x3400~0x4DBF、0x4E00~0x9FFF、0xF900~0xFAFF、
    0x20000~0x2FA1F、0x30000~0x3134F,外加 0x3007(〇);段里的空档照算汉字(整段口径);
  • 全角半角只做 ASCII 那一档:
    0xFF01~0xFF5E 与 0x21~0x7E 一一对应(差 0xFEE0),全角空格
    0x3000 与半角空格互换;半角片假名那一档(0xFF61~0xFF9F)不换;
  • 中文数字:
    小写(一二三…十百千万亿 与 〇○两)与大写(壹贰叁…拾佰仟萬億)都认,可以带
    负 / 正(或 - / +)前缀;两种形态各读各的;认不出就整条给假(不猜、不跳过);不报错、不停机。

提供的函数(13 个):UTF-8 三件 + 汉字四件 + 全角半角三件 + 中文数字三件;
逐条的参数与返回值见本页末尾那张公开方法表。

英文对照:库里不另立英文函数(中英切换只管关键字与内建函数名,现有几个库也都只有中文名)⇒ 没有英文别名。

复杂度:UTF-8 三件 O(文字数);汉字个数 / 只留汉字 / 转全角 / 转半角 一趟扫完;
中文数字转整数 O(文字数);整数转中文数字 / 金额大写 O(结果的字数)。

边界(如实登记):

  • 中文数字有两条读法(按整串里有没有单位字分):
    ① 有单位 ⇒ 按"数位 + 单位"读,并且按汉语
    语法校形:同一段里单位须严格递减(十百 / 千千 给假)、万 / 亿 前面必须有东西(万亿 给假)、
    零 只能当占位(零十 给假,连写两个 零 也给假)、段内数字不能连着写(一万二 可以,一万二三
    给假),十 前面可以没有数字(十五 = 15);② 没有单位 ⇒ 按"逐位"读(二零二六 = 2026、零零一 = 1);
  • 口语省略单位的形态按字面读:
    一万五 读成 10005(不猜成 15000)、一亿五 读成 100000005 ——
    要口语意思就把单位写全;不做"上下文猜数位";
  • 廿 / 卅 / 半 不认(要它们自己先换写);
  • 超出 32 位按回绕(与语言里 + - * 同一个口径);要按值域校验请在调用方自己看范围;
  • 整数转中文数字 出小写那一套(负数写 负);十位那个"一"只在整串最高那一段省(十 / 十五 /
    十万 / 十二万),底下照写(10010 ⇒ 一万零一十);要票据那种大写用 金额大写;
  • 金额大写 收的是"分"(12345 = 123.45 元):
    分 是 32 位有符号 ⇒ 能表示到 21474836.47 元为止;
    元位为 0 时也写成 零元X角X分;分 为 0 时末尾写 整(角 有、分 没有也写 整);拾 不省;
  • 只出人民币那一套字(元 / 角 / 分 / 整),不认"人民币"前缀、不管繁体(萬 / 億 只认不写);
  • 不碰 宽度.hb 那份"占几格"的表:
    一个汉字占两格是排版口径,这里只管"是不是汉字"。
