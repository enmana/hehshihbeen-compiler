数据与函数的样子

语言的规矩与坑都在这儿(取自 中间层速查 的手写说明,与命令行 hbcc --help-text 同一份正文);关键字与内建函数的逐条说明看站点里那两节(它们是从表现场生成的)。

变量 a = 5; // 32 位字;初值也能写式子:变量 c = a * 2 + 1
短整数 b = 300; 字符 c = 'A'; // 紧致布局,常量越界报错
字节 buf[8]; // 数组:常量下标=编译期偏移,变量下标=运行时算地址
短整数 表[5] = [10, 20, 40]; // 数组可以写字面量初值 […](只收常量;写几个算几个,剩下补 0)
字节 缓冲[] = [1, 2, 3]; // 带初值时长度可以不写:个数 = 初值个数(定长数组)
字符 字[4] = ['H', 'i', '!']; // 字符数组初始化的常见写法(末尾自动是 0,能直接 输出)
整数 袋[3][4]; // 多维数组:定长、行优先、2~4 维,最后一维挨着放
袋[1][2] = 7; 整数 v = 袋[r][c]; // 每一维的下标都能是常量或变量(袋[r][c] 的字节偏移 = (r*4 + c)*4)
// 逐维查越界:报错点明是第几维、那一维几个元素
短整数 网格[2][3] = [1, 2, 3, 4, 5, 6]; // 初值按行铺开(最后一维最快),写几个算几个,剩下补 0

  • 多维数组的 .长度() 是第一维的长度(行数);各维乘起来封在「数组长度」那道上限里
  • 不做(报错当场说):列表的列表(整数 表[][];)、当数组参数传、取地址、整块赋值 ——
    要整块用就摊平成一维自己按下标算,或者写成结构数组(结构 一行 { 整数 格[4]; } + 一行 表[3];)
    表[行号].格[列号] = 7; // 结构数组的元素里再取一次下标:行里的定长数组字段当"下一维"
    // 地址照旧 下标 × 步长 线性累加;越界两处都查 —— 外面说行数,
    // 里面说"字段 '格' 只有 4 个元素"(报的是元素个数,不说它是第几维);行里放动态列表
    // (整数 格[];)也认:表[行号].格.添加(7); / 表[行号].格[列号]
    点 坐标 = [3, 4, 9]; // 结构也能这样:按字段声明顺序给(字段是结构/数组/字符串的不收,请分别赋值)
    坐标 = [1, 2, 3]; // 整体赋值也能用字面量(没写到的格归 0)
    // 两个括号各管一件事:[ … ] = 数组 / 列表的初值与整体赋值;{ … } = 语句块,两处不混用
    枚举 颜色 { 赤, 绿, 蓝 }; // 枚举:一行写完,成员是编译期常量(赤 = 0 / 绿 = 1 / 蓝 = 2)
    枚举 方向 { 上 = 3, 下, 左 = 10 }; // 想自己定值就写 = 3(认十进制与 0x、认负号),后面的成员接着它 +1
    颜色 画 = 绿; // 枚举名当类型名用:底层就是有符号 整数 4 字节,不占存储
    如果 (画 == 颜色.蓝) { … } // 成员在表达式里就是常量(裸名 蓝 与全名 颜色.蓝 都能写);
    // 比较 / 情况 / 循环头 / 数组初值 / 传给方法 里都能直接用
  • 变量 / 数组 / 结构字段 / 方法参数(含 颜色 表[])/ 返回值 / 引用 / 静态容器的常驻字段,
    处处都能写枚举名 —— 与写 整数 逐字节同构(机器码里就是一个立即数)
  • 约束(报错当场说):两个枚举的成员不许隐式互赋(颜色 某色 = 上; 报错并给改法);
    枚举不进 [] 当数组长度(没有「区间类型」这种用法);两个枚举里不能有同名成员(裸名会说不清指谁)
    [整数, 整数] 一份 = [7, 3]; // 元组:类型位置写一对方括号 —— 几个值捆成一份
    测试输出(一份.项0); // 不写名字时成员依次是 .项0 / .项1 …(从 0 起)
    [整数 商, 整数 余] 带名 = [17, 5]; // 想给成员起名就写 类型 名字,取的时候用真名(带名.商)
  • 成员就是字段:能读能改(一份.项1 = 8;);[整数, 整数] 副本 = 一份; 是整块拷一份(改副本不动原件)
  • 元素类型能是:基础类型 / 枚举 / 结构 / 另一个元组([[整数, 整数], 整数] 也认)
  • 元组数组([整数, 整数] 表[3];)、当参数传(与结构一样按地址传:被调方改的就是调用方那份)、
    当返回值、当结构字段、引用 [整数, 整数] 指 = 账; —— 处处都能用
  • 名义制:
    [整数, 整数] 与 结构 点 { 整数 x; 整数 y; } 是两个类型(长得像也不能互赋)
  • 不做(报错当场说):拆包([整数 商, 整数 余] = …)、元素是 字符串 的元组、空元组 []
    方法 除法(整数 被除, 整数 除数) 返回 [整数, 整数] // 多值返回:一次带回几个值
  • 返回 [被除 / 除数, 被除 % 除数]; —— 成员按顺序算出来、写进"调用方给的那块"(与结构返回同一套隐藏槽)
  • 调用方 [整数, 整数] 商余 = 除法(17, 5); 接住,再 商余.项0 / 商余.项1 按字段读(不必先落局部变量)
  • 元组值也认在声明初值([整数, 整数] 账 = [3 + 4, 6 * 2];)与整体赋值
    (表[i] = [表[i - 1].项0 + 1, …];)这两处 —— 三处共用同一段"按成员填块"的代码
  • 成员的式子可以是参数 / 局部变量 / 别的调用结果;没有拆包,要拆就 整数 商 = 商余.项0;
    短整数 分数[]; // 列表:个数不写 —— 声明形状和数组一样,空着就是列表
    分数.添加(85); // 放末尾;编译器能算出要几个就先算,算不出就自己长大(池里要地方)
    分数[0] = 0; 分数[1] = 91; // 取/改和数组完全一样([] 里是第几个)
    分数.长度(); 分数.清空(); // 现在几个 / 长度归零(内存不动,很快)
