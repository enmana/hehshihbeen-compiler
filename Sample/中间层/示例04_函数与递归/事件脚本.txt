# 示例04_函数与递归 的事件脚本(H82 批 3)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一份只投"点左边一层,看它的参数与返回值":
#     · 第 27 帧:点左边第 2 格(第 1 层)—— 屏幕 (200, 146)。
#       摆位:最上面那格的顶边 `栈顶 = 104`、层间隔 `框距 = 28` ⇒ 第 1 层 = 104 + 28 = 132,
#       它的范围是 132 ~ 156,146 正落在里面(x = 200 在 12 ~ 512 之内)。
#       命中测试就是 `(点y - 104) / 28`(= 1)⇒ 底下三行当场换成**这一层**的
#       "参数 / 算了什么 / 返回值";这一屏正好是 `fact` 压到第 4 层的那一刻,
#       点中的第 1 层是一条"等下一层"的式子,与最上面那格(栈顶)当场区分得开。
#     · 第 0 ~ 26 帧什么都不投:逐帧推进自己往前走 ——
#       第 1~5 步一层层压到最深的 5 层(fact(5) → fact(1))、第 6~9 步一层层弹回来、
#       第 10 步起演 `sq` / 较大 / 求和 那几段"压一层就回来",第 23 步整座栈弹空之后再绕回第 0 步。
#     · 第 29 帧:宿主收起窗口(主循环收到 类型 == 1 就收手,不再刷新)。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
