# 示例61 的事件脚本:一份**写死的输入** —— 第几帧按哪个键。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次提交一帧、进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   ⚠ 图形事件里**键盘没有"抬起"** ⇒ "按住走"表达不出来;这一篇是
#     **输入脉冲 + 意图保持**(一次 `按键` 把那个意图点亮 3 帧),
#     所以下面点一下 W、人就会往前走一小段(与真人按住时的自动重复同一条口径)。
#
#   这一串编排的是一小段连招:**第 0 帧停在标题页**(不放事件),
#   回车进战斗,然后走 → 斩 → 走 → 斩 → 走 → 斩 → 冲刺 → 左转。
#   跑完应当是:**三刀全中 / 连击 3 / 敌人被斩(血 0)/ 体力被冲刺吃掉一些**。
