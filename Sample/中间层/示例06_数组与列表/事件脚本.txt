# 示例06_数组与列表 的事件脚本(H82 批 2)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一份投的是"在格子上点四下"(每一帧都是一次完整的 按下 + 抬起 = 点一下):
#     · 第 1 帧:点 `字节 buf[5]` 的第 2 格   —— 元素宽 1 ⇒ 字节偏移 = 2 × 1 = 2,现值 29;
#     · 第 2 帧:点 `整数 words[2]` 的第 1 格 —— 元素宽 4 ⇒ 字节偏移 = 1 × 4 = 4,现值 305419895
#                (同一屏上跟上一格比一比:格宽不同、字节偏移的步子也不同);
#     · 第 3 帧:点右边那个「＋ 添加一个」  —— `分数.添加(长度 × 10)` 真加一次,列表自己长到 5 格;
#     · 第 4 帧:点列表刚长出来的那一格    —— 元素宽 2 ⇒ 字节偏移 = 4 × 2 = 8,现值 40。
#   第 5 帧(最后一帧)什么都不投:于是这一屏留着"选中的是列表第 4 格"的样子,宿主随后投关窗请求。
#
#   一行的写法:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
#   坐标口径 = 窗口内坐标,与 `画文字` / `画矩形` 用的是同一套 x / y。
