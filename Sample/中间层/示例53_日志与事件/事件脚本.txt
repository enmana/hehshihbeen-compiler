# 示例53 的事件脚本:一份**写死的输入** —— 第几帧投哪个事件。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次提交一帧、进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
#   键名:回车 / 空格 / 左 / 字母A / 数字5 / F3 / 鼠标左键(也可以直接写键码数字)。

帧数 5

帧 0 按键 回车
帧 1 移动 120 55
帧 2 按下 鼠标左键 40 52
帧 2 抬起 鼠标左键 40 52          # 按下 + 抬起 = 在(40, 52)点了一下
帧 3 按键 字母A
帧 4 按键 退出
