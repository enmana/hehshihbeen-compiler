# 示例39_栈与队列 的事件脚本(H82 批 4)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一屏的动画只认 `帧计`(第几帧),到点就夹回(见主程序 B / C / D 三段):
#     · 帧   1 ~  48:栈一帧压一位(2026 的 11 个余数),每 2 帧一位;
#     · 帧  55 ~ 100:栈一帧弹一位(倒着拼出 11111101010),每 2 帧一位;
#     · 帧 110 ~ 134:环形队列 入 1~5(满)→ 出队 1 个 → 再入一个写进 0 号格(绕回去了);
#     · 帧 140 ~ 168:最小堆 放 5 / 1 / 9 / 3 → 看最小 → 取最小 ×2 → 再取最小(空了给假、不动收值);
#     · 帧 170 之后:整屏定住不动。
#
#   这一份投的是"在格子上点三下"(每一帧都是一次完整的 按下 + 抬起 = 点一下):
#     · 第  60 帧:点**栈底**那一格(左上那一摞最下面,坐标 110,425)
#                  ⇒ 底下两行说"栈里第 0 格(从栈底数)装 0 ……" —— 那一刻栈正好 11 格压满;
#     · 第 130 帧:点**环形队列里绕回去的那一格**(0 号格,坐标 132,330)
#                  ⇒ 说清"6 住在 0 号格,是出队顺序的第 2 个"(队头已经挪到 1 号格);
#     · 第 156 帧:点**最小堆里堆[1] 那一格**(下半屏第二格,坐标 200,517)
#                  ⇒ 说清它的优先级与它在第几位 —— 那一刻堆里是 3 / 5 / 9。
#   第 176 帧(最后一帧)什么都不投:于是这一屏留着"选中的是堆[1]"的样子,宿主随后投关窗请求。
#
#   一行的写法:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
#   坐标口径 = 窗口内坐标,与 `画文字` / `画矩形` 用的是同一套 x / y。
