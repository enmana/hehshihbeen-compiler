#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一份按的是"1 + 2 * 3 =":每个键 = 一次"点一下"(按下 + 抬起,程序在**抬起**那一帧结算)。
#     键位:四行四列的下标 0~15(`7 8 9 /` / `4 5 6 *` / `1 2 3 -` / `0 ( ) +`),
#           底下两个宽键 = 16(`清空`)/ 17(`=`);
#     键的矩形:方键 100×48,左上角 (62,200);宽键 200×48,左上角 (62,396) 与 (262,396)。
#   按的次序:1(下标 8)→ +(下标 15)→ 2(下标 9)→ *(下标 7)→ 3(下标 10)→ =(下标 17),
#   最后那一帧 `=` 现场求值 ⇒ 显示区那行变成 `= 7`。第 14 帧宿主收起窗口。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
