# 示例08_模块与库 的事件脚本(H82 批 3)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一份投的是"在左边两栏里点三行":
#     · 第 2 帧:点 数学 栏 第 4 行(数学.累加器)—— 屏幕 y ≈ 208(行0 108 + 3 × 30);
#     · 第 7 帧:点 统计 栏 那一行(统计.求和(表))—— 屏幕 x ≈ 200(统计 栏 164~304)、y ≈ 118;
#     · 第 9 帧:再点回 数学 栏 第 1 行(数学.求和(表))—— 屏幕 y ≈ 118。
#   于是这一屏把四种样子都画出来了:右栏先跟着蓝底走 → 钉在 数学.累加器 → 钉在 统计.求和 →
#   又钉回 数学.求和;剩下的帧里蓝底每帧往下走一格(7 行走完绕回第 1 行),第 13 帧宿主收起窗口。
#   ⚠ 第 7 帧那次点的正是"蓝底走到 统计 那一行"的下一帧 ⇒ 屏幕上绿底(点中的)与蓝底(光标)
#     落在两栏各一行,一眼看得出这两个高亮是两码事。
#
#   命中测试:`行0 108` / `行距 30` / `行左 16 与 164` / `行宽 144 与 140` 与源码里那几行摆位是
#   同一组数;点击在主循环的浅一层结算(先记进 有一下 / 点x / 点y,再单独一层判)。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
