# 示例41_链表与树 的事件脚本(H82 批 4)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一屏自己会**逐帧推进**(不用喂鼠标也一直在动):上半屏沿着链表一格一格走
#   —— 正着走 5 步(10 → 50)、再倒着走 4 步(40 → 10),9 步一轮;下半屏换个节点高亮,7 个一轮。
#   所以这份脚本投四次「点一下」(按下 + 抬起),看的是"点中的那一格换成金边、底下那两行说它的账":
#     · 第 3 帧:点**链表第 2 格**(屏幕 x ≈ 150、y ≈ 100,命中口径 12 + 序号 × 116)
#       ⇒ 底下那行说它的前驱 / 后继(这一格是 20:前驱 10、后继 30);
#     · 第 9 帧:点**树最左下角那个节点**(屏幕 x ≈ 100、y ≈ 330:第 3 层、框在 70~130)
#       ⇒ "第 3 层;左孩子 没有,右孩子 没有;这棵子树 1 个节点";
#     · 第 16 帧:点**树根**(屏幕 x ≈ 280、y ≈ 215:第 1 层那一个)
#       ⇒ "第 1 层;左孩子 30,右孩子 70;这棵子树 7 个节点";
#     · 第 24 帧:点**链表最后一格**(屏幕 x ≈ 500:第 5 格)
#       ⇒ 底下换成"它是尾,后继是 0"那一句。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
