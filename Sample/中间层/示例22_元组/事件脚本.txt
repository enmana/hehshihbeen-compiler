# 示例22_元组 的事件脚本(H82 批 3)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一屏自己会**逐帧推进**:没点到的时候,蓝底每帧沿成员往后走一格
#   (#0 → #1 → … → #11 → #0)。所以这份脚本只投两次「点一下」(按下 + 抬起),
#   看的是"手点一格 ⇒ 蓝底停到那一格、底下三行当场换成它":
#     · 第 2 帧按下 / 第 3 帧抬起 = 点格子阵**第 2 行第 1 列**那一格(#2,屏幕 x ≈ 150、y ≈ 250)
#       —— 就是 `带名.商`,底下三行出"它在这一捆里的第 1 个 / ①『带名』… / 现在的值: 17";
#     · 第 10 帧按下 / 第 11 帧抬起 = 点**第 6 行第 2 列**那一格(#10,屏幕 x ≈ 420、y ≈ 440)
#       —— 就是 `套.项0.项1`(元组套元组那一格,上面 ③ 打出来的 2)。
#   点完蓝底继续往后走(#3、#4 …):"点中的那一格"由底下三行说了算,蓝底说的是"这一帧演到谁"。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
