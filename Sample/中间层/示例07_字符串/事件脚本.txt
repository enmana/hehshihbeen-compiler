# 示例07_字符串 的事件脚本(H82 批 1)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一份投的是"在左边那排操作按钮上点两下":
#   第 1 帧按下 / 第 2 帧抬起 = 点第一格(① 等长替换,屏幕 y ≈ 88);
#   第 3 帧按下 / 第 4 帧抬起 = 点第二格(② 不等长替换,屏幕 y ≈ 128);
#   第 5 帧什么都不投 —— 宿主收起窗口。于是这一屏把"这段文字被改过两次"的三种样子都画出来了:
#   第 0 帧 abc、第 2 帧起 aCc、第 4 帧起 中Cc(长度都是 3 个字,屏幕宽度从 3 格变成 4 格)。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。

帧数 5

帧 1 移动 60 88
帧 1 按下 鼠标左键 60 88
帧 2 抬起 鼠标左键 60 88
帧 3 移动 60 128
帧 3 按下 鼠标左键 60 128
帧 4 抬起 鼠标左键 60 128
