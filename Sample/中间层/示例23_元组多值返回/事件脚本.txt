# 示例23_元组多值返回 的事件脚本(H82 批 3)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一屏自己会**逐帧推进**:每帧走一小步,按"先算 → 再返回 → 再落变量"三步演一行,
#   走完一行换下一行。所以这份脚本只投三次「点一下」(按下 + 抬起),看的是
#   "手点左边一行 ⇒ 右边同号的那一格一起亮,底下两行换成那一对":
#     · 第 3 帧抬起 = 点**第 1 行**(`除法(17, 5)` ⇔ `商余`,屏幕 x ≈ 150、y ≈ 145)
#       ⇒ 底下出"第 1 个返回值 3 → 商余.项0;第 2 个返回值 2 → 商余.项1"(就是上面 ② 那两个数);
#     · 第 9 帧抬起 = 点**第 3 行**(`换算(185)` ⇔ `时分`,屏幕 y ≈ 265)
#       ⇒ 底下出"3 → 时分.项0;5 → 时分.项1"(成员是式子:一个局部变量 + 一个参数运算);
#     · 第 15 帧抬起 = 点**第 5 行**(声明初值 `[3 + 4, 6 * 2]` ⇔ `初值对`,屏幕 y ≈ 385)
#       ⇒ 底下出"7 → 初值对.项0;12 → 初值对.项1"。
#   点完三步继续往前走:"点中的那一对"由底下两行说了算,亮着的那一格说的是"这一帧演到哪一步"。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
