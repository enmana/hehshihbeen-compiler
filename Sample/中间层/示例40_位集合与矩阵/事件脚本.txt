# 示例40_位集合与矩阵 的事件脚本(H82 批 4)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一屏自己每帧走一步埃拉托斯特尼筛(每 34 帧一轮,32 位窗口里 11 个素数走完),
#   所以脚本投四次点击就够了 —— 四次落在三块不同的小格上(坐标与窗口里命中区用的是同一组数):
#     · 第 7 帧按下 / 第 8 帧抬起 = 点**第 0 行的位 5**那个格(屏幕 75, 140):
#       这时筛已走过 2 与 3,底下那行说"0 号字第 5 位:现在 0(没划掉)⇒ 素数";
#     · 第 18 帧按下 / 第 19 帧抬起 = 点**第 0 行的位 8**那个格(屏幕 102, 140):
#       同一块屏、晚十一帧 —— 8 早被素数 2 划掉了,底下那行改口说"现在 1(划掉了)";
#     · 第 30 帧按下 / 第 31 帧抬起 = 点**矩阵第 0 行第 0 列**那一格(屏幕 46, 344):
#       底下说"第 0 行第 0 列:值 = 11",那一格换蓝边;
#     · 第 42 帧按下 / 第 43 帧抬起 = 点**并查集第 1 行第 2 格** = 成员 7(屏幕 250, 498):
#       底下说"成员 7 属于第 7 组:这一组一共 3 个成员"。
#   帧数 48 够筛走完一轮(34 帧)还多出十几帧。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
