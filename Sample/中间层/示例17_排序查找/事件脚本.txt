# 示例17_排序查找 的事件脚本(H82 批 5)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一份投的是两次"点一下"(按下 + 抬起 = 一次点击;程序在**抬起**那一帧结算):
#     第 3 帧抬起 = 点中间那排柱子的第 2 根(x = 220,y = 300)⇒ 底下那行换成"第 2 格 · 值";
#     第 6 帧抬起 = 点上半那排格子的第 0 格(x = 70,y = 124)⇒ 换成"第 0 格 · 值"。
#   第 8 帧宿主收起窗口。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。

帧数 8

帧 2 移动 220 300
帧 2 按下 鼠标左键 220 300
帧 3 抬起 鼠标左键 220 300

帧 5 移动 70 124
帧 5 按下 鼠标左键 70 124
帧 6 抬起 鼠标左键 70 124
