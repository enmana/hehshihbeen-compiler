# 示例58_真人头 的事件脚本
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc -p 示例58_真人头.hbp --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一篇是"转着看"的三维演示:**一帧就够** ——
#   示例头注释里那五个读数(`画了几面 / 面积负 / 覆盖像素 / 亮最小 / 亮最大`)都是第 0 帧打出来的,
#   多喂几帧只是多转几个角度、读数照样只有第一帧那一份(自检比的就是那一份)。
#   一帧就收手的原因见 `未做任务清单.md` 台账序号 24:这一族的图形 dump 一帧上千条,给不了 `// 预期输出:`。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
