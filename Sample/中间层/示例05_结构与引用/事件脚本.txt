# 示例05_结构与引用 的事件脚本(H82 批 3)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一屏自己会**逐帧推进**:没点到的时候,高亮每帧沿字段往下走一格(第 8 行绕回第 1 行)。
#   所以这份脚本只投五次「点一下」(按下 + 抬起),看的是"手点一格 ⇒ 两栏同时亮、连线连过去":
#     · 第 2 帧:点**左栏第 3 行** `队[1].y`(屏幕 x ≈ 100、y ≈ 185)
#       ⇒ 右栏第 6 行(R3 取址那一行)同时亮 —— 结构数组元素里的字段,是取址改的;
#     · 第 6 帧:点**右栏第 2 行** `引用 整数 ry`(屏幕 x ≈ 350、y ≈ 155)
#       ⇒ 反过来亮左栏第 2 行 `q.y` —— 从右边点也认,两栏说的本来就是同一件事;
#     · 第 11 帧:点**左栏第 6 行** `t.cnt`(屏幕 y ≈ 275)
#       ⇒ 右栏第 4 行(引用 字节 cnt)同时亮 —— 引用能指到结构尾上那个 1 字节字段;
#     · 第 15 帧:点**右栏第 3 行** `变量 pa`(屏幕 y ≈ 185)
#       ⇒ 亮左栏第 4 行 `l.end.y` —— 存着地址的变量,指的就是嵌套两层的那个字段;
#     · 第 19 帧:点**左栏第 5 行** `t.cells[2].y`(屏幕 y ≈ 245)
#       ⇒ 这一格**没人指着**:右栏一行都不亮、连线也不画(底下那行字会说明)。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
