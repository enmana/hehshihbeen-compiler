# 示例20_多维数组 的事件脚本(H82 批 2)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一屏自己会**逐帧推进**:没点到的时候,高亮每帧沿行优先顺序往后挪一格
#   (`#0 → #1 → … → #11 → #0`)。所以这份脚本只投三次「点一下」(按下 + 抬起),
#   看的是"手点一格 ⇒ 左边那一格与右边摊平的同一格**同时亮**,底下两行也跟着换":
#     · 第 1 帧:点左边格阵的**第 1 行第 2 列**(屏幕 x ≈ 70、y ≈ 180)
#       ⇒ 亮的是 #6,底下出 `袋[1][2] ⇔ 平[6]`(就是上面 ① 那个格子,值是 7);
#     · 第 5 帧:点右边摊平那一排的 `平[3]`(屏幕 x ≈ 350、y ≈ 210)
#       ⇒ 亮的是 #3 —— 从右边点也认,两边本来就是同一块内存;
#     · 第 13 帧:点右边摊平那一排的最后一格 `平[11]`(屏幕 x ≈ 508、y ≈ 210)
#       ⇒ 亮的是 #11 = 袋[2][3],底下那两行给出 `((2 × 4) + 3) × 4 = 44`(与上面 `地址(...)` 那条断言同一个数)。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。

帧数 16
