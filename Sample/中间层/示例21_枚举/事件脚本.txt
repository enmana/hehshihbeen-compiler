# 示例21_枚举 的事件脚本(H82 批 3)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一份投的是"先在左边点一格成员,再在右边点一行":
#     · 第 3 帧:点左边第 6 格(`方向.左 = 10`)—— 屏幕 y ≈ 140(格顶 72 + 5 × 40);
#     · 第 5 帧:点右边表里第 3 行(`颜色.蓝 = 2`)—— 屏幕 y ≈ 216(行0 148 + 2 × 34);
#   于是这一屏把"绿底停在刚点中的成员上、蓝底照旧每帧往下走一格"的样子画出来了:
#   第 3 帧起底下一行说 `方向.左 = 10`,`颜色.蓝` 那一路的值 / 走哪一支 / 能不能当数组下标也都被翻出来过。
#   命中测试:`格高 40` / `行距 34` 与源码里那两行摆位是同一组数,点击在浅层结算。
#   ⚠ 事件投在**第几帧**、`帧数` 就得写到**它后面**(排在第 5 帧的事件,`帧数 5` 到不了 —— 脚本检查会当场拦住)。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
