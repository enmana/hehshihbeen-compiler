# 示例09_堆与数据结构 的事件脚本(H82 批 4)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一份投的是"点四下"(每一帧都是一次完整的 按下 + 抬起 = 点一下):
#     · 第 2 帧:点**二叉树里的一个节点** —— 屏幕上 (168, 356)。
#       摆位:根那一层的顶边 `树y0 = 288`、层间隔 `层距 = 52` ⇒ 第 2 层(值 3 那个节点)
#       的范围是 y 340 ~ 374,356 正落在里面;x 140 ~ 196 也是它(值 3 判 168)。
#       命中测试 `(356 - 288) / 52 = 1` ⇒ 底下两行当场换成"值 3 那一块住在哪一块(块号 · 堆内偏移)、
#       根 的左孩子指着它、它指着 值 1 与 值 4 那两块"。
#     · 第 6 帧:点**堆块地图上的第 3 块**(链表头节点,值 3)—— 屏幕上 (120, 124)。
#       地图那一排从 x=16 起、块宽 = 字节数 × 4 像素(8 字节 ⇒ 32 像素)、块间 14 像素,
#       所以第 3 块是 x 108 ~ 140;y 104 ~ 144 是块本身,124 落在里面。
#       这一下与上面那一下说的是同一块内存(节点就是堆块)—— 两处点哪边都落到同一块。
#     · 第 10 帧:点**那块已经 释放 掉的灰框**(第 9 块)—— 屏幕上 (476, 124)。
#       它 x 464 ~ 496(申请回来又释放掉的那一块,画成灰框);
#       底下两行换成"这一块已经回到空闲表里、释放后再 取字 / 存字 会被当场拦住"。
#     · 第 11 帧:点**二叉树的根**(值 5)—— 屏幕上 (280, 305)。
#       根那一层 y 288 ~ 322、x 252 ~ 308;底下两行换成"根指针 树根 指着它、
#       它指着 左 值 3 与 右 值 8 两块"(左/右那两个块号也是从块里 `取字` 现读的)。
#     · 第 0 ~ 11 帧里其余那些帧什么都不投:逐帧推进自己往前走 ——
#       高亮沿"链表 3 个节点(值 3 → 2 → 1)→ 二叉树 5 个节点(值 5 / 3 / 8 / 1 / 4)"
#       走一圈(8 帧一轮,结构图里的方框与地图上那一格一起亮)。
#
#   一行的写法:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
#   坐标口径 = 窗口内坐标,与 `画文字` / `画矩形` 用的是同一套 x / y。
