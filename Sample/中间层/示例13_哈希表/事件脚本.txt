# 示例13_哈希表 的事件脚本(H82 批 2)
#
#   这是一份**写死的输入**:第几帧投哪个事件。自检与
#   `hbcc --run --无头 --事件脚本 事件脚本.txt` 都按它喂 ⇒ **不开窗也能把这一屏跑得一模一样**。
#
#   帧号口径:打开窗口之后是第 0 帧;每 `刷新()` 一次进下一帧。
#   跑满 `帧数` 帧之后,宿主投一个「关窗请求」(类型 1),主循环据此收手。
#
#   这一份投的是"点三下"——两次键格、一次桶行(命中口径与窗口里画的坐标是同一组数):
#     · 第 3 帧按下 / 第 4 帧抬起 = 点右边第 3 格键 `xyz`(屏幕 y ≈ 130);
#     · 第 5 帧按下 / 第 6 帧抬起 = 点右边第 4 格键 `id` (屏幕 y ≈ 155);
#       —— 这两个键在 **8 个桶**时都落 **0 号桶**(拉链上 id 在前、xyz 在后),
#          点它们就是为了把"两个键挤一个桶"这件事在底下那两行里说清楚;
#     · 第 7 帧按下 / 第 8 帧抬起 = 点左边第 1 行 `桶 0`(屏幕 y ≈ 90),
#       底下当场画出这一桶**当前**挂着的链。
#   窗口那一半自己一帧推进一步(第 0 步空表 → 第 8 步中文键),`帧数 12` 够它推完还剩三帧。
#
#   一行一条:`帧 帧号 事件类型 [参数…]`;`#` 或 `//` 起头是注释。
#   事件类型:关窗 / 按键 / 移动 / 按下 / 抬起(英文 close / key / move / down / up 也认)。
