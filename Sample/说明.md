# Sample 示例说明

**每个示例都是一个标准工程**:一个目录 + 一个 `.hbp` 工程文件 + `主程序.hb`(入口)。
用法:IDE `文件 → 打开项目…` 选那个 `.hbp`,再 编译 / 执行;命令行 `hbcc -p 目录\名字.hbp --run`。

> 手动测核心功能与边界跑 `综合_核心与边界`;学语言照 `Sample\中间层\` 从 `示例01` 往下读(编号即难度顺序)。

## 带 UI 的示例怎么写

能演成"开一个窗口、把结果画出来 / 列出来"的示例就写成窗口程序(`示例14` / `示例15` / `示例16` 是样板)。
四个出参 `类型` / `键码` / `鼠标x` / `鼠标y` 写在**顶层**;要拼文字就先 `包含 "../../库/string.hb"`。

```text
逻辑 开着 = 打开窗口("窗口标题", 520, 300); // 没有图形能力的宿主给 假
如果 (开着)
{
  逻辑 收手 = 假;
  当 (!收手) // 收事件 → 重画 → 刷新
  {
    当 (取事件(类型, 键码, 鼠标x, 鼠标y)) // 轮询:取空了给 假,不阻塞
    {
      如果 (类型 == 1) { 收手 = 真; } // 关窗请求
    }
    如果 (!收手)
    {
      清屏(0xFF101018); // 即时模式:每帧重画一遍
      画文字(20, 20, "标题", 0xFFE8E8F0);
      刷新(); // 不刷新就不显示
      等待(120); // 让出一帧
    }
  }
  关闭窗口();
}
停止
// 预期输出: ……原来那些数……|打开窗口 标题="窗口标题" 宽=520 高=300|……|刷新 命令=N|关闭窗口
```

- **断言(`测试输出`)在前、开窗在后**;示例配一份 `事件脚本.txt`;⚠ 收到关窗请求还接着刷新,超过 `帧数 + 4` 帧**当场报运行期错误**。

**写窗口容易踩的**:

| 坑 | 现象 / 办法 |
|---|---|
| ⚠ **`格式化` 只认 `{0}`** | `格式化("%d", 42)` **不报错**、原样返回 `"%d"`;要写 `格式化("{0}", 42)` |
| ⚠ **每帧别拼字符串** | 给字符串变量赋字面量、或把 `转字符串(值)` 当实参,**每次都在池里占一块新的**(老的还不了)⇒ 几秒就报“池用完了” |
| `跳出` | “只能用在 循环/选择 内”;主循环收手用 `收手 = 真` + `如果 (!收手)` 包住重画 |
| **`返回 格式化(...)` 不行** | 直接当返回值会**静默停机**;先落一个局部字符串再 `返回` |

## 命名风格(怎么方便怎么来)

- **标识符随便起**(不是语言要求;中文优先指的是**关键字**);关键字中英等价、可以混写:`如果`/`if`、`循环`/`for`、`当`/`while`、`函数`/`func`、`结构`/`struct`。
- **类型名**:`字节` `短整数` `无符号短整数` `整数` `无符号整数` `字符` `逻辑` `字符串` `地址` `var`(都有英文别名);**`整数` / `短整数` 有符号**,要 0~4294967295 写 `无符号整数`。

## 库\ —— 用语言自己写的库(靠 包含 内联展开)

`Sample\库\` 里是普通 `.hb` 源码,靠 `包含` 内联展开(库里的结构和主程序里的一样能用);常用的有 `int64.hb` / `int64s.hb`(64 位)、`string.hb`(字符串)、`float32.hb` / `float64.hb`(软件浮点)。**每个库文件的头注释就是它的用法说明**。

> **`float32.hb` 与 `float64.hb` 不能同时 `包含`** —— 内部同名(结构 `宽整数` / `除法结果` / `开方结果` 等);要同时用就得各写一个小包装。

```text
包含 "../库/int64.hb" // 中英:包含/import;相对路径以"当前文件所在目录"为基准
u长整数 左 = 造u长整数(65535, 0, 0, 0); // 0x0000_0000_0000_FFFF
u长整数 结果 = u长整数加(左, 造u长整数(1, 0, 0, 0)); // 结构参数按地址传
```

- 同一个文件被包含多次只展开一次;相对路径按**被包含文件所在目录**继续解析;库函数只收**基础类型参数**。

## 方法 `方法` / `静态 方法`(一个词管三件事)

```text
方法 数学() // 1) 无状态容器 = 一段代码的名字空间
{
  平方(short x) 返回 short // 成员不用写 函数/方法 前缀;要返回值就得写 `返回 类型`
  {
    返回 x * x;
  }
}
测试输出(数学.平方(7)); // 49

静态 方法 棋盘(short 宽, short 高) // 2) 静态方法 = 带常驻状态的容器
{
  short 步数 = 1; // 括号参数就是常驻字段(零初值)
  宽 = 8; // 普通语句 = 程序开头跑一次的初始化脚本
  面积() 返回 short
  {
    返回 宽 * 高; // 成员之间直接叫名字
  }
}
测试输出(棋盘.面积()); // 64
```

- 三种写法同一个词:`方法 名()` 是容器,`方法 名(参数)` 是普通函数(`函数` 的糖),`静态 方法 名(参数)` 才是带状态的容器;**没有继承 / 多态,也没有多实例**;容器不能嵌套。
- 调用直接写名字:`f(a)` / `容器名.成员名(a)`;要调**汇编标签**写 `调用 标签`。**旧的 `调用 f(a)` 写法已退役**。

## 表达式与函数调用

```text
var a = 2 + 3 * 4; // 14:乘先算 优先级:| > ^ & > << >> > + - > * / % > 一元负 > ()
测试输出(距离(平方(3), 双(2))); // 调用当实参,测试输出也吃表达式
```

- 常量在编译期折叠;**变量 / 字段 / 数组元素用到才取值**;调用结果跨 `CALL` 落在**临时槽**暂存。关系符、`&&` `||` `!`、三目也能写进普通表达式;一元 `~` = 按位取反。
- **复合赋值十个全有**:`+= -= *= /= %= &= |= ^= <<= >>=`;字符串只认 `+=`。**起名字的规矩**:保留字(关键字、类型名、全部 ISA 指令名)不能当变量 / 字段 / 容器名,撞上会得到**带改法**的报错。

## 字符串 `字符串 名字 = "你好";`

```text
字符串 欢迎 = "世界"; // 声明:初值拷进自己的缓冲区(数据在编译器开的池里)
输出行(欢迎.长度()); // 2 —— 长度与下标都按**文字**(Unicode 码点)算
欢迎 = "更长的内容在这里"; // 赋值:容量不够自动 ×2 扩容
字符串 英文 = "abc";
文字 第二字 = 英文[1]; // 下标取出来是一个 `文字`(码点),能存起来
英文[1] = 'B'; // 写回去 → aBc(换的字**可以不等长**,后面自动挪位)
如果 (英文 == "aBc") { … } // 比较:== != 与字典序(按 UTF-8 字节,前缀短的算小)
拼接到(英文, "!", 第二字); // 拼接:字符串 / 字节 / 文字
```

- **下标写回可以不等长**;**唯一还等长的**是"字符串参数"(会给人话错误并给改法)。**当返回值**由调用方给头地址、被调方整份拷进去;**值语义**:改副本不影响原名。
- ⚠ **`字符串[i]` 取一次是 O(下标)**(UTF-8 里"第几个文字"得**从头数**)⇒ **逐字扫一整块就是 O(n²)**。实测同一个 **9600 字节**的文件:**逐文字**扫(`文字 c = 块[i]; i = i + 1;`)跑出 **5.45 亿条指令**(75 秒,自检的 6000 万条护栏当场判"停不下来");**先把整块搬进模块级 `字符 区[4100]`**(`拼接到(区, 块)` **一趟 O(n)**)再按**字节**下标走(`区[i]`,一次 O(1))⇒ **451 万条(0.6 秒,快 120 倍)**。
  **写库遇到"大文件 / 大缓冲逐字节"就照这条走**;`校验和.hb` / `命令行选项.hb` / `大文件工具.hb` / `网页.hb` 都是这么写的。**这不是缺陷是口径** —— H80 已按"判定不做语言面改动"结案(2026-10-15),口径钉在这里与帮助《字符串》一节。
- 明确不支持(有明确报错):取地址、用 `引用` 指它、给字符串参数重新赋值(想写回就加 `出`);**能放进结构 / 数组 / 列表**(结构字段的数据在**堆**里,要自己 `释放`)。

## 字符串参数可写回 `字符串 出 名字`(英文 `result`)

字符串参数默认是**只读**的(在函数里改它会当场报错);参数前面多写一个 `出`,它就成了"可写回"的:

```text
函数 取全名(字符串 出 结果, 字符串 姓, 字符串 名)
{
  结果 = 姓; // 里面一赋值,外面那变量**当场**就变了
  拼接到(结果, "·", 名); // 装不下就连调用方的容量一起长大
}
```

- 传的是调用方那个字符串的**头**(地址 / 长度 / 容量 三个字),不是整份复制,也能**转发**给别的函数。实参只能是**字符串变量**。英文别名 `result`,**不叫 `out`**。

## 程序自带的测试 `测试 名字`(块头一行、`{` 另起一行;英文 `test` / `assert`)

`// 预期输出:` 管"**整个程序**的输出对不对"(一份程序一条);`测试` 管"程序里**每一小块**对不对":

```text
测试 字符串
{
  字符串 名字 = "张三";
  断言 名字 == "李四", "名字该是李四"; // 逗号后面跟一句说明(可省)
}
```

- 不成立时打印 `第 N 行:断言失败:<条件原文>(说明)`,然后**接着往下跑**;每块跑完打印 `测试 名字:共 N 条断言,失败 M 条`(也算程序输出);失败记进**错误槽**。

## 控制台输入输出

```text
输出字符 R2 // 原始字节:R2 的低字节(ISA 的 OUT)
输出换行 // 原始字节:换行
输出(值); // 给人看:十进制 / 字符串内容,不补换行
输出行(值); // 同上,末尾补一个换行
无符号整数 c = 读取字符(); // 没有输入(EOF)时给 0xFFFFFFFF
字符串 行 = 读取行(); // 读一行
整数 数 = 读取数字(); // 读十进制数
```

- `测试输出(值)` 是**调试用**:按**变量声明的类型**决定有无符号(`无符号整数` 里打印 4294967295、`整数` 里打印 -1),而且它**不动用户寄存器**。

## 宿主能力:文件 / 目录 / 时间

```text
写文件(路径, 内容) 返回 逻辑 覆盖写(文件不存在就新建)
追加写文件(路径, 内容) 返回 逻辑 接在原有内容后面
读文件(路径, 内容变量, 上限) 返回 逻辑 上限是编译期数字
建目录(路径) 返回 逻辑
列目录(路径, 清单变量, 上限) 返回 逻辑
删文件(路径) 返回 逻辑
环境变量(名字, 值变量, 上限) 返回 逻辑
当前时间() 返回 整数 Unix 秒;失败给 0
```

- 全都**返回 `逻辑`**:真 = 成功、假 = 失败;**不抛异常、不停机、不写错误槽**;目标变量容量不够会自己从池里换一块;相对路径相对**程序运行时**的当前目录。
- ISA 只多一条 `宿主调用`,**能力由宿主注入**:纯虚拟机里跑一律返回 **假**。

## 流式读写:一块一块地读大文件

`读文件` / `写文件` 是**整份进出**的 —— 大文件只有"开一条流、要几块读几块"这一条路:

```text
打开读流(路径, 句柄) 返回 整数 句柄用 `整数` 接;用不了给 -1;文件必须已经存在
读一块(句柄, 块, 上限) 返回 整数 0 = 到末尾,-1 = 失败(上限是编译期数字)
定位(句柄, 偏移) 返回 整数 挪到从文件开头算的第几个字节(0 = 成功)
关读流(句柄) 返回 整数 0 = 成功;关掉之后那个句柄一律作废
打开写流(路径, 句柄) 返回 整数 不存在就新建;**已存在就从头写起**
写一块(句柄, 内容, 字节数) 返回 整数 返回真写下去的字节数;`字节数` 写 0 = 整段都写
关写流(句柄) 返回 整数 **先冲刷到盘上**再关;写完不关可能少一截
```

- 收尾常见写法:`块长 = 读一块(句柄, 块, 4096); 当 (块长 > 0) { …; 块长 = 读一块(句柄, 块, 4096); }`;句柄变量**要先声明再赋值**。
- 同时最多开 64 条;打不开 / 句柄作废 / 表满各有状态码(2 / 22 / 23)。规格见帮助**《第30节·流式读写》**。

## 网络:裸 TCP

`取网址` 是"宿主替你把 HTTP 取回来";这一族是**裸 TCP** —— 自己写协议、两个程序通话、当服务端等人来连:

```text
连到(主机, 端口, 句柄) 返回 整数 **同步**;句柄用 `整数` 接,失败 -1
  (**不叫 `连接` / `connect`**:那两个名字是 `string.hb` 里段拼装的)
发送(句柄, 数据) 返回 整数 真发出去的字节数(-1 = 失败)
接收(句柄, 数据变量, 上限) 返回 整数 收到的字节数:0 = 对端关掉了,-1 = 失败
关闭(句柄) 返回 整数 关连接 / 关监听(0 = 成功;句柄作废)
监听(网卡地址, 端口, 句柄) 返回 整数 绑网卡(要写 IP)+ 端口
接受(监听句柄, 句柄) 返回 整数 收连接(**同步阻塞**)
主机解析(主机, 地址变量) 返回 逻辑 主机名 → 地址
```

- **主机 + 端口必须在 `.hbp` 的 `网址` 表里声明**,这一族**只认写到端口的声明** —— 不在表里连试都不试;连接最多等 5 秒(到点给状态 18),收发全同步阻塞。
- 句柄与流的句柄看法一样但两张表**互不相干**,监听句柄只能 `接受`;同时最多开 32 条;手机端与独立 exe **没有这一族能力**。

## 运行时:睡眠 / 冲刷 / 改名 / 临时目录

```text
睡眠(毫秒) 返回 整数 **阻塞**睡满再往下走(0 = 睡满;负数不睡、给状态 9)
冲刷(句柄) 返回 整数 把**写流**的缓冲落盘(0 = 成功;流还开着)
改名(旧路径, 新路径) 返回 逻辑 换名字或位置;**目标已存在就整体替换**
临时目录(目录变量, 上限) 返回 逻辑 本机临时目录写进那个 `字符串` 变量
```

- `睡眠` 给**命令行小工具**用:界面程序里睡主循环 = 窗口卡住,那里请用 `等待(毫秒)` 或 `定时.hb`。
- `改名` 与 `移动到` 分工:`移动到` 碰上已存在的目标**拒绝**,`改名` 则**整体替换** —— 安全保存 = "先写临时的,再一次 `改名` 盖上去"。这四条每个宿主都有。

## 异步:别让一次阻塞调用把整帧卡住

前面那几节(`读文件` / `读一块` / `接收`)都是**全同步**的;这一节把"等"挪到**宿主后台线程**上:

```text
发起异步(种类, 参数一, 参数二, 参数三, 任务) 返回 整数 立刻给任务号(排不上 -1);任务 = 一个 `整数` 变量的名字
  种类 1 读文件 `(1, 路径, 内容变量, 上限, 任务)`
  种类 2 写文件 `(2, 路径, 要写的串, 要写的字节数, 任务)`
  种类 3 连接 `(3, 主机, "", 端口, 任务)`
任务就绪(任务号, 状态, 字节数) 返回 整数 0 还没好 / 1 好了 / 2 这一趟失败 / 3 号作废 / 22 号不成形
取消任务(任务号) 返回 整数 0 = 取消成功 / 3 = 号已作废 / 22 = 号不成形
```

- 等就绪一律写成 `当 (任务就绪(任务, 状态, 个数) == 0) { }` —— **别用 `睡眠` 去等**。返回 `1` 时结果搬进 `状态`(0 = 成了)与 `字节数`,**任务号当场作废**。
- **读文件的内容**在说"好了"那一刻直接写进 `发起异步` 指定的 `字符串` 变量;最多同时占 **32** 个任务;`种类 3 连接` 要先写进 `.hbp` 的 `网址` 表。

## 错误怎么传

HB **没有异常**(没有"抛出 / 接住"这种写法)。失败分三类,只有第三类要你自己写代码处理:

| 哪一类 | 谁处理 | 你怎么写 |
|---|---|---|
| 编译期的毛病 | 编译器 | 不用写:报错带**行号 + 说明 + 改法** |
| 运行期的守卫(越界 / 列表满 / 池用完 / 栈溢出 / `断言` 不成立) | 虚拟机自己拦下 | 不用写:写进"错误槽",退出码非 0;`断言` 与 `测试` 只记不停 |
| "失败也算正常结果"的那一类(宿主能力 / 你自己写的函数) | 你的代码 | 靠返回值传 —— 见下面的**标准结果形状** |

**标准结果形状 = 一个"成不成 + 值"的小捆**,缺省用**元组**(`返回 [式子, 式子];`):

```text
方法 取一半(整数 数) 返回 [逻辑, 整数]
{
  如果 (数 < 0) { 返回 [假, 0]; }
  返回 [真, 数 / 2];
}

[逻辑, 整数] 结果 = 取一半(10);
如果 (结果.项0) { 输出行(结果.项1); } 否则 { 输出行("这个数取不了"); }
```

要**错误码 / 说明**就换成结构(`逻辑 成;` + `整数 值;` + `整数 错误码;` + `字符串 说明;`)。

- **宿主能力**那一族是老约定:返回 `逻辑`(真 = 成功),**失败不停机、不写错误槽**;拿到 `逻辑` 就当结果形状用。
- **哨兵值**(-1 / 0 / 空串)只在"合法值里根本不可能出现那个数"时才用。**不做**:异常、`结果<值, 错误>` 那种**泛型**结果类型(HB 不加泛型)。
- 规格见帮助**《第28节·错误怎么传》**(站点里那一节标题写作 `28,错误怎么传`);例子 `示例25_错误传播\`。

## 网络:同步 GET 一次

要"拉一个网址的数据",用 `取网址` / `取网址状态码`(与 `运行进程` 同一档:**要工程文件里声明白名单**):

```text
取网址(网址, 内容变量, 上限, 超时毫秒) 返回 逻辑 同步 GET 一次,响应体写进那个 `字符串` 变量
取网址状态码() 返回 整数 上一次的 HTTP 状态码(没取过/连不上/超时给 0xFFFFFFFF)
```

- `上限` 是响应体最多多少字节(**编译期数字**,超了给 假、**不截断**);`超时毫秒` 写 0 = 10000;HTTP 2xx 给 真;**不跟跳转**。**只能连 `.hbp` 的 `网址` 表里声明过的 主机 + 端口**。

## 工程文件 `名字.hbp`(多文件工程清单)

在项目目录里放一个 JSON,写明"这个工程由哪些文件组成、入口是哪个、带哪些资源":

```json
{
  "名称": "多文件_跨文件共享",
  "启动文件": "主程序.hb",
  "文件": ["主程序.hb", "工具.hb", "共享.hb"],
  "汇编": ["热路径.hba"],
  "资源": ["输入.txt"],
  "内存": "1MB",
  "堆": "64KB"
}
```

- 路径都**相对工程文件本身**;启动文件排第一个。**`内存`** 可写 `1MB` / `512KB` / 字节数,不写就是 1MB(**4KB ~ 64MB**);**`堆`**:`申请` 那块,不写 64KB,不能比 `内存` 大。
- **资源**随工程带,**第一个资源自动作为虚拟机输入流**;**白名单** `可执行文件`(给 `运行进程`)、`网址`(给 `取网址` 与网络那一族,**必须写到端口**);**`汇编`** 里的 `.hba` 接在 `文件` 表展开结果**之后**,标签全局共用。**没有工程文件时**:目录里所有 `.hb` 一起编译,入口 `主程序.hb`。

> **工程文件就是"名字共享的范围"**:列进来的文件属于同一个编译单元,**函数 / 结构 / 全局变量**互相都能用、**不限顺序**。同名会报错:要两个库各有一个 `求和`,给文件加一行 `模块 名字`。

## 取址 `地址(...)`(也叫 `address(...)`)

```text
p = 地址(表); // 整数组 → 基址
p = 地址(表[2]); // 元素 → 基址 + 2×元素宽(常量下标编译期算,变量下标运行时算)
p = 地址(点.y); // 结构字段 → 基址 + 字段偏移
```

- 全局数据 → `取地址 Rd, 槽标签`;局部 / 数组 → `MOV Rd, R15` 再 `加立即数`(帧相对);汇编行只能用**寄存器**。
- `地址(...)` 的结果**可以**存进命名变量;但它是个**跟布局有关**的数(优化开 / 关两次编译会平移),要比就比**差值**。名字是**函数 / 方法**时取的是**代码地址**(见帮助**《第29节·回调》**)。

## 数组与列表的写法:`整数 表[3]` / `整数 表[]`(为什么不是 `整数[] 表`)

```text
整数 表[3]; // 定长 3 个(个数是声明时就写死的常量)
整数 表[3] = [1, 2, 3]; // 字面量初值 `[…]`:写几个算几个,剩下补 0(`{ }` 只留给语句块)
整数 表[] = [1, 2, 3]; // 带初值时长度可以不写:个数 = 初值个数(定长数组,不是列表)
短整数 分数[]; // 个数**不写** = 列表:编译器数得清 `.添加()` 几次就精确给那么大
函数 求和(整数 nums[]) 返回 整数 // 数组参数:括号跟在**参数名**后面
```

- **语法形状是“类型 名字[长度]”,方括号属于名字,不是类型的一部分**;`[数字]` = 定长数组,`[]` = 列表,两者取用完全一样(`表[0]`、`.长度()`)。
- **列表元素不能取地址**(长大时要搬家),`引用` 也不能指向 —— **有意设计**。**那怎么办**:a) 要不动的地址就写**定长数组**;b) 按下标读改用 `表[i]`;c) 共享可改数据用 `引用` 指变量 / 结构变量 / 数组元素。写成 `整数[] nums` 会当场报 `参数名非法`。

## 函数(中间层)

```text
func add(short a, short b) 返回 short // 中英:函数/func;参数类型只支持基础类型
{
  返回 a + b; // 返回值由编译器安排落点(不用自己管寄存器)
}
测试输出(add(3, 4)); // 7
```

- 参数与局部变量都在**固定 96 字节的帧**里,用帧指针 R15 相对寻址 → **支持递归**;撞上上限会报"再加这个 W 字节就是 Y 字节,上限 96"。R15 **用户代码不要用**;其余 R0~R14 可用。
- **数组 / 结构当参数 ✅**(按地址传,实参只能是变量 / 字段 / 数组元素)。主程序末尾的 `停止` 可以省:只要有**函数定义**或 `申请`,编译器就自己**补一条 `停止`**。

## 流程控制补充:`遍历` 与 `选择`

```text
选择 (值) // 多分支:值和 switch 一样必须是变量或寄存器
{
  情况 1
  { … }
  情况 2, 3   // 一个分支管几个值
  { … }
  情况 10..20 // 闭区间
  { … }
  默认
  { … }
}

遍历 (当前, 起始 游标, 数量 剩余) // 从地址 游标 起,按**字节**走过 剩余 个
{
  总数 = 总数 + 当前; // 每个元素按 `当前` 声明的类型宽度取值
}
```

- `选择` 与 `如果/否则 如果` 是两条路:值集中、按值跳用 `选择`,条件复杂用 `如果`。`遍历` 是唯一的"内存扫描"写法;`跳出`/`继续` 也认 `跳出 2`。

## 注意:数据地址要避开代码区

变量槽紧跟代码之后,**代码长度会长**;把数据写到 `0x100` 这类低地址,程序一大就会写进自己的指令。示例统一用 `0x2000` 起的高地址。

## 注意:字节存取 vs 字存取(写汇编最容易踩)

| 指令 | 宽度 | 用途 |
|---|---|---|
| `加载` / `存储` / `加载间接寻址` / `存储间接寻址` | **1 字节** | 字符、源码字节、词缓冲、名字表这类逐字节的数据;指针遍历 |
| `取字` / `存字` / `取字间接` / `存字间接` | **4 字节**(小端) | 地址、指针、计数器、任何可能超过 255 的 32 位值 |

把 32 位槽(比如源指针 `0x1000`)用 `加载` 读出来只会拿到**低字节 `0x00`**;排错:`--dump 0x2000,64` 看内存、`--trace 起,止` 单步看寄存器。

子程序没有自动保存寄存器:**子程序用到的每个寄存器,调用方都要当成"会被改掉"**。
